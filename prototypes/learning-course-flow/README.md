# 学习工作台课程流程设计稿

这是独立于正式应用的静态设计稿。顶部步骤条可切换四个页面；课程大纲和课时内容均可打开编辑弹窗。表单和 AI 按钮只用于展示界面状态，不保存数据。

设计决策：

1. 「课程设置」统一填写主题、水平和参考资料；当前水平占满表单宽度，参考资料默认可见。
2. 「课程大纲」外层只读展示课程目标与整体学习路径，不显示课时明细和完成状态；点击编辑大纲后在弹窗里手动编辑或用 AI 优化。
3. 「课时内容」用两行表格维护课时，点击课时进入编辑弹窗；AI 助手在右侧，先确认目标课时再生成或优化。
4. 「项目实训」独立成第四步，按可选环节呈现；保存课程需要完成全部课时，启用实训时还需保存项目计划。

设计稿已移除各步骤底部的解释性提示，只保留任务所需信息和操作。

从仓库根目录运行 `python3 -m http.server 5182 --bind 127.0.0.1 --directory prototypes/learning-course-flow` 后打开 <http://127.0.0.1:5182/>。
