# 办公室中枢

正式中枢已应用确认过的正向工位设计。房间、椅子和六只猫咪使用像素素材；工位有 20 种与活动对应的屏幕画面，猫咪按照各自偏好自主安排办公室活动。

在应用左侧点击「中枢」，进入 `#/hub`。办公室组件负责自己的纵向滚动，并根据可用容器宽度调整布局，适配应用导航栏和窄窗口。

## 操作

- 点击场景中的猫咪或名字，打开对应角色的详情弹窗，查看当前活动、性格、偏好与最近做过的事情；没有底部详情栏或成员切换栏。
- 猫咪自主选择接下来想做的事情；用户只观察，不指定活动或状态。
- 每只猫都有不同偏好，倾向于多做喜欢的事，也会做其他事情。弹窗中的「性格与偏好」为只读说明。
- 活动只显示正在做什么，不显示工作进度条；场景没有区域文字标签。顶部仅保留办公室标题，没有状态统计或暂停按钮。
- 直接点击工位显示器，查看放大的屏幕；没有单独的「打开屏幕」按钮。猫咪详情与屏幕弹窗共用奶油色纸面、浅木色边框和淡紫色点缀，点击关闭按钮、空白遮罩或按 Escape 均可关闭，并恢复触发按钮的键盘焦点。
- 猫咪会自己决定离开或返回工位，沿过道行走。共享过道每次通过一只猫，避免相互穿过。
- 查看弹窗时猫咪仍自主活动，详情和屏幕随当前状态更新。页面不可见时内部计时暂停；系统开启减少动态效果时，位置切换直接完成，活动仍自主进行。

## 自主活动与偏好

活动共 23 种：

- 办公：做计划、写代码、查资料、写文稿、整理文件、检查成果、处理邮件、准备讨论、学习新知识、设计界面、安排日程、分析数据、琢磨点子。
- 休闲：看动画片、看电影、刷网页、打游戏、听音乐、读闲书、玩益智小游戏。
- 休息：打盹、喝咖啡、伸懒腰。

Mewvis 偏爱统筹与规划，Lihua 偏爱开发与学习，Orange 偏爱调研、网页和动画，File 偏爱整理与打盹，Writer 偏爱写作、阅读与电影，Review 偏爱检查与益智游戏。

活动通过带偏好的随机选择产生。每只猫都能选到所有活动，排除刚做的同一件事，并降低最近做过的事情被再次选择的概率。选择工位活动时会避开其他猫咪正在做或已排队准备做的同一件事，因此亮着的屏幕内容各不相同。离开工位的屏幕保持待机画面，多只猫咪可以同时休息。每项活动持续约 18–72 秒，初始进度错开；下一项活动只选择一次，等待过道时不会反复重选。

动画、电影、网页、游戏和待机画面沿用现有素材；其他 16 种工位画面为对应活动绘制独立界面，不连接真实影音服务、网页或游戏。活动持续时间仅用于自主切换，不以进度条展示。猫咪的办公、娱乐和休息是本地场景活动，不表示真实智能体正在执行对应任务；办公室不会发起真实任务、调用运行时或保存设置。

## 验证

```sh
node --experimental-strip-types scripts/office/route.test.mjs
node --experimental-strip-types scripts/office/autonomous.test.mjs
pnpm exec vite build --outDir /tmp/mewvis-hub-build
pnpm exec tsc --noEmit --pretty false
```

正式入口为 `apps/client/src/workbench/pages/hub/office/index.tsx`，直接实现并导出 `MewvisOffice`。活动、偏好与路径定义在该目录的 `office-model.ts`，自主选择、计时与移动在 `office-simulation.ts`，样式为 `index.css`，素材位于 `assets/`。样式和动画均限定在办公室内，不设置全局正文、按钮、标题样式。

临时预览页面及其过程截图已移除；活动与路径测试位于 `apps/client/scripts/office/`，直接使用正式模型。正式中枢路由及外部应用代码沿用原入口，功能代码位于办公室目录。
