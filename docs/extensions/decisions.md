# 智能判断插件

源码位于 `apps/extensions/decisions`，插件 ID 为 `isle.decisions`，随内置插件自动构建和加载。它借鉴类型化判断的使用方式，复用当前会话的模型，不连接 Jev，也不需要单独的 TypeSafe API Key。当前模型是否远程运行取决于会话的模型配置。

## 使用

1. 完整重启桌面开发服务，进入插件管理，确认“智能判断”已启用。
2. 选择聊天模型，在输入框输入 `/`，选择“需求分类”“方案评分”或“执行条件判断”，随后填写待判断的材料并发送。
3. 在插件管理的“智能判断”设置中编辑或添加模板，保存后通过 `/` 按模板名称引用。模型也可以根据模板描述调用同名工具。

例如：选择“需求分类”，输入“请给聊天记录增加全文搜索，支持按日期筛选”。或者选择“方案评分”，输入需要评估的完整方案。

## 插件拥有的逻辑

- `choice`：从 2–10 个配置选项中选择一个字符串。
- `score`：按从低到高的 2–10 个档位返回整数分值，从 0 开始。
- `noul`：返回布尔值；这里仅借用是非判断的概念，不实现 Jev 的概率输出语义。
- 每种结果均包含 `type`、`value`、`confidence`、`reason`。材料不足时允许 `value: null`，状态为 `abstained`。
- 自评置信度低于配置阈值时状态为 `review_required`，否则为 `accepted`。`accepted` 仅表示通过格式与阈值检查，不代表事实已验证。
- `confidenceSource: "model_self_report"` 明确指出这是普通模型自评，未经统计校准。此插件没有专用训练、采样概率或“零幻觉”保证。
- 严格校验结果类型、选项、评分范围和额外字段。只允许完整 JSON 或单个 JSON 代码块；格式错误最多重新调用一次，仍失败则报告错误，不回退为虚构结果。模型请求失败及取消不自动重试。

## 边界

插件只依赖 SDK。流程为：命令/工具 → 插件组织模板 → `host.tasks.run` → 当前 Agent 适配 → 当前模型 → 插件校验和格式化结果。模板配置、判断语义、阈值与输出格式都由插件维护，不进入宿主协议。

`tasks.run` 新增通用的可选参数 `tools: "none"`，用于仅做评估的子任务。宿主将其映射为内部空工具列表、空技能/应用资源及空访问范围，原有子任务默认行为不变。判断不会继承原聊天历史；只发送命令中的材料与模板说明。子任务仍沿用宿主的输出记录和取消机制，聊天中可看到原始模型输出及校验后的结果。

此版本一次执行一个模板，仅报告判断，不根据结论自动操作业务或分支协作流程。未来可以在插件内扩展批量判断、规则执行器与流程分支；跨插件调用或静默推理需要按实际需求扩展宿主能力。

## 验证

```sh
pnpm --filter @isle/extension-decisions check
pnpm --filter @isle/extension-decisions test
pnpm --filter @isle/extension-decisions build
pnpm --filter @isle/server test:extensions
```

单元测试验证类型约束、弃答、低置信度、配置校验、取消、失败和重试；服务端集成测试使用本地模型桩验证真实 SDK → 宿主 → Pi 链路，不调用付费模型。
