# 口袋文明

口袋文明位于 `apps/applications/builtins/pocket-civilization`，使用应用自有页面呈现固定斜俯视的分层小岛。居民、局部雨云、花朵、手账、法则卷轴和可编辑手册独立于场景底图，支持缩放、暂停演出、查看居民和翻阅事件。

## 游玩流程

从第7天的雨点镇开始。点击卷轴的「改写」，在手册右页写下新的法则，例如「说真话的人，身边会开花。」。写下后仍停在当天；卷轴同时显示现行法则与下一天生效的新法则，支持撤回。点击「推进一天」后，居民动作、对白、场景效果和手账一起更新。

首版支持真话、故意说谎、帮助和真诚夸奖四类条件，以及局部下雨、脚边开花两种效果。复杂的否定、例外或复合条件不会被静默简化。重复真话种花会引出岛民请愿，玩家可以决定「重复的真话不再开花」或「每次真话都算」；解释从下一天生效。

「故事模式」使用明确标注的手写情节，不调用模型。初次打开即可体验法则、请愿和历史延续。点击右上手册，进入「游玩」可以连接「智能演绎」并选择宿主中已经配置的模型。

## 会留下变化的小岛

世界保存各地点的花丛、雨伞铺库存与零钱、居民位置和个人经历。开花通常留下2簇花，单处最多30簇；改变法则不会抹去已有花丛。道路旁的花量影响通行状态、居民目标和请愿条件。收拢一次最多4簇花，会把同样数量的材料收入店前花篮。

雨伞铺起初有6把旧伞和2簇花。编鲜花伞消耗1把旧伞和2簇花；卖出旧伞或鲜花伞分别获得1或2枚零钱；进货花费2枚零钱、补进2把旧伞。缺少材料的行动不会进入候选，重复收同一处花的安排也不会结算。场景中的花丛、花篮和鲜花伞与这些存量对应，可点击打开「小岛」页查阅小账和实际后果。

居民只记录自己参与或直接收到的行动。承认错误、帮助、夸奖和反复否认会改变邻居对自己的信任；永久经历保留首次承认、做伞、售卖、清路等变化。每人保留最近12段个人记忆和有限的已知事实，重要经历与关系独立于手账截断保存。当前心愿根据这些经历和眼前的库存、通行情况调整。

每日提交后，居民沿固定地图的道路绕过屋顶走向行动地点；拜访会跟随对方当天已经发生的移动。打开手册和暂停按钮会暂停演出，关闭后继续；重载直接呈现已保存的位置，不重新结算。演出使用已有角色素材与轻微动作，不包含自由寻路或新的完整角色动作帧。

## 会继续发展的故事

「鲜花伞与一条小路」由实际行动推进：小满制作鲜花伞、发现重复真话能够种花，小路上的花逐渐变多，镇长找青禾商量。只有这些行动和道路状态真的发生，居民才会发出第一封请愿。先决定重复真话是否继续开花；解释生效后，居民会发出第二封请愿，商量日常怎样照顾小路。

选择合作收花，会提高居民清理道路的行动优先级，把回收材料送进花篮；选择果园试种，会让小满把重复真话的尝试搬到果园，邻居继续清理路边旧花。两类选择组合成四种结局。约定不会凭空增加资源，必须实际执行、恢复通行并再次卖出鲜花伞，故事才会收尾。换法则会让尚未结束的种花故事暂告一段落，已经留下的资源和经历保留。

手账提供故事时间线、已处理请愿和最终回音。「把道歉变成日常」则根据阿团的承认与后续帮助，记录小满从顾虑到重新信任的过程。这些记录独立于近期事件列表保留，不按固定天数制造剧情。

## 智能演绎

智能演绎复用公开的应用 Chat SDK 创建无界面会话。当前应用的默认工作区由数据 SDK 获取，模型与启用的插件由现有宿主解析。应用不直接读取凭据，也不导入判断插件内部实现。

每次推进由应用先列出当前材料、地点和个人经历允许执行的候选。导演根据居民各自的记忆、目标和关系选择3位不同居民的行动，再通过现有结构化插件命令 `mewvis.decisions/evaluate` 判断法则是否触发。库存、移动、收花和关系由程序结算，模型不能提交资源补丁。该命令在现有 Agent Runtime 中直接分发。应用校验命令返回的结果、状态和依据；`accepted` 与判断值分别处理，`review_required`、`abstained` 或错误不会被当作成功，也不会退回固定故事。

判断插件在现有策略下可能要求宿主确认。应用沿用会话授权并显示「请到 Mewvis 主窗口确认这次智能判断」，不提供审批入口。插件未启用、模型缺失、取消、超时或结果格式不完整时保留原来的日期、法则和存档。

### 争议复核与续跑

导演选好行动后，应用先保存下一天的演绎草稿；每完成一件判断，再保存一次。草稿与世界放在同一个记录中，以版本检查保护并发写入。需要复核、弃答、或明确表示存在解释争议的判断都会暂停，后面的行动暂不判断，日期、库存与关系也不结算。网络错误、停止和关闭页面后，已保存的进度仍然保留。

从「查看待续演绎」或手账打开草稿，可以查看已完成的判断、争议依据、当事人的事实与近期记忆，并写下至多300字的复核说明。说明会先保存，再重连模型；它是玩家的理解，不能作为新增世界事实。重试使用原来的行动安排，跳过已采纳的判断，携带此前依据从中断处继续，仍由原智能判断插件独立复核。连续复核仍不明确时会继续停留，不人工冒充插件结论。

只有全部判断明确后才整体提交新一天。若最后一次保存失败，完整草稿可直接重试提交，不再调用导演或判断模型。放弃草稿不会改变当天资源；改写或撤回法则、处理请愿、切换模型或返回故事模式，会放弃不再适用的草稿，页面会提前说明。

## 数据与边界

世界状态在当前应用的 `application-data` 中保存到单个版本化记录；模型演绎结束并通过校验后才整体提交新一天。演绎会话引用单独保存。关闭界面会取消正在等待的演绎并释放观察，聊天历史由已有宿主管理。

世界只读写当前格式 `pocket-civilization-v3`，存储键为 `pocket:world:v3`，不提供旧存档迁移。新小岛直接初始化库存和开场记忆；保存与加载会校验资源、居民、故事与演绎草稿，损坏数据不会被静默重置。

应用声明 `application-data`、`application-workspaces` 和 `chat`，不提供文件、网络或程序执行工具。实现和美术素材归本应用；宿主协议、公共 SDK、Agent Runtime 和判断插件实现不因本应用改变。

## 开发与验证

在仓库中运行：

```sh
pnpm --filter @mewvis/pocket-civilization dev --port 5186
pnpm --filter @mewvis/pocket-civilization check
pnpm --filter @mewvis/pocket-civilization test
pnpm --filter @mewvis/pocket-civilization test:runtime
pnpm --filter @mewvis/pocket-civilization build
pnpm --filter @mewvis/builtin-applications build
pnpm --filter @mewvis/pocket-civilization preview:packed
pnpm --filter @mewvis/pocket-civilization preview:packed -- --review-fixture
```

开发预览提供隔离的内存工作区与存储，适合验证故事模式与界面。真实模型和插件使用 Mewvis 内的应用会话。`test:runtime` 使用临时数据目录、真实 Runtime 与判断插件、隔离本地模型桩，并模拟测试用户在宿主确认调用；不读取用户模型配置或消耗付费模型。

`preview:packed` 在 `http://127.0.0.1:5187/` 加载已构建的应用 UI，使用与宿主相同的沙盒文档和公开 SDK 桥接、隔离内存数据。视觉对比与交互验收记录位于应用目录的 `design-qa.md`。请愿与解释绑定当时的法则，新法则不会继承旧解释。

`--review-fixture` 在5188端口提供独立的固定草稿样本，页面明确标注未调用模型，用于检查复核界面的排版、重载和放弃流程；它不模拟模型成功复核。真实插件输出下的断点续跑由领域集成测试覆盖，真实 Runtime 的插件分发另由 `test:runtime` 验证。截图和验收记录位于应用目录的 `qa/stories-and-review`。
