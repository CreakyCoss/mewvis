# 学习工作台

`@isle/learning` 是独立的 Isle 内置应用，源码位于 `apps/applications/builtins/learning`。
它使用公开的 `@isle/app-sdk` 聊天、数据和工作区接口，已登记在 `apps/applications/registry.json` 中，随内置应用构建打包；默认启用。

## 使用

在应用列表打开「学习工作台」，页面占满常驻导航栏之外的应用工作区，通过导航栏切换到其他页面。课程库的名称与课程总数收在顶栏，列表区提供导入、搜索与继续学习；首次进入时可从空状态打开示例课程，无需模型即可阅读三个课时、完成单选题并记录学习进度。课程卡片直接显示当前课时和进度，提供「编辑课程」，复制 JSON 与移除放在「更多」中。

「创建课程」只打开一个课程弹窗，按「课程设置 → 课程大纲 → 课时内容 → 项目实训」四步进行，已到达的步骤可通过步骤条返回编辑。设置页在同一面板填写主题、占满表单宽度的水平选择和默认可见的参考资料。大纲外层只读，仅展示课程简介、总目标和宏观学习路径，不展示或维护课时；点击创建或编辑后在弹窗里修改，也可从同一弹窗用 AI 生成或优化，采用 AI 结果会保留课时数据。课时页以单栏紧凑列表维护唯一一份课时数据。点击「添加课时」直接打开空白弹窗，只有标题、目标、正文、示例、知识要点和测验通过必填校验并保存后才加入列表；点击已有课时整行可编辑，AI 生成与优化也在同一弹窗中进行。项目实训是单独的可选步骤，可手动创建项目草案或让 AI 生成项目框架。弹窗右下角始终提供「暂存」，至少添加并完成一课后可在第四步「保存课程」。暂存课程可从首页点击「继续编辑」恢复；保存后状态变为「已完成」。课程卡片的「编辑课程」直接加载该课程的数据。学习工作区的顶栏固定，目录、正文和 AI 导师各自滚动；导师默认常驻。小屏可将导师展开为专注对话视图。

课程工作台数据使用当前四步格式；首次打开此版本时清空旧版学习工作台数据，不读取或转换旧课程记录。

「创建课程」接受主题、水平及可选参考资料。资料可以粘贴，或一次追加最多 5 个 UTF-8 TXT / Markdown 文件（每个文件上限 80 KB，合计文本上限 20,000 字）；导入文本标出文件名作为来源提示，不提供逐段引用。进入「课程大纲」后，点击「创建大纲」打开编辑弹窗；已有大纲点击「编辑大纲」打开相同弹窗。可在弹窗内手动编辑，也可用 AI 生成或优化，在宿主 Chat 中选择模型并开始生成。

大纲通过校验后，点击「采用并保存结果」，可继续手动调整，再点击弹窗中的「保存大纲」。大纲页展示课程主题、简介、总目标和学习路径；外层始终只读，未保存的弹窗修改可以取消。大纲不会预建课时。课时页负责添加、编辑和移除课时，以及调整顺序（最终 1–8 课）。点击「添加课时」直接打开空白弹窗；只有完整课时通过必填校验并保存后才进入列表。点击已有课时可编辑全部内容，弹窗底部只有「取消」和「保存」。

在课时弹窗内使用 AI 输入区生成新课时或优化已有课时；每次只处理一课，完成后预览并采用。格式错误、模型失败或停止时，已采用的其他课时保留；可在原会话重试或要求修正 JSON。任务会话引用和已采用内容保存到该课程，离开工作台后可以继续编辑。未发送的空会话不保证跨宿主重启恢复，连接失败时可新建会话重试。所有课时准备完毕后，在项目实训步骤点击「保存课程」。保存重试复用同一个课程 ID。

课程卡片的「编辑课程」打开同一弹窗，直接加载课程数据，可以返回设置、大纲、课时或项目实训步骤。学习页不提供编辑入口。已完成课程发生编辑后变为「暂存」；再次完成全部课时并保存后恢复为「已完成」。暂存课程只能继续编辑，不能进入学习页。重做的课时获得新的内容 ID，其旧测验、完成状态和导师会话引用不再沿用；未改动课时保留原 ID 与学习进度。

课时弹窗支持修改标题、目标、正文、示例、知识要点，以及单选、多选和简答题的题干、选项、答案、解析、评分标准。可添加/删除题目和选项，提交时使用与 AI 输出相同的校验规则。所有必填内容通过校验后才能保存；未修改内容的保存保留原课时 ID，内容变化则生成新 ID，以免旧测验和导师上下文附到修改后的内容。

已生成的课时还可选择「AI 局部修改」，填写具体要求后在宿主 Chat 中选择模型。模型只返回要改的字段，应用将字段合并到原课时并按完整课时规则校验；未知字段和无实际变化的结果会被拒绝。预览并显式采用后更新当前课程。内容变化会更新课时 ID，旧作答和导师上下文不会附到新内容。

学习页提供目录、正文、例子、要点，以及单选、多选、简答三种题型。选择题本地判分，多选必须完整匹配答案；简答题先保存作答，再点击「连接 AI 评阅」，选择模型开始评分。AI 按参考答案和评分标准返回每题 0–1 分及反馈，评分结果须匹配当前作答批次和全部简答题，通过校验后显式采用保存。AI 评分仅供学习参考，失败或停止不会抹掉已保存答案。

「全部再练」创建新的作答批次；如果有答错或未满分的题目，也可以「只练需巩固的题」，沿用上次已掌握题目的答案，重新填写需要巩固的题目。最近一次作答及历史记录显示“掌握参考”，按已评分题目的得分比例估算，并明确提示尚未评分的简答题；它不是跨课程能力诊断。每课保留当前作答及最多 8 条先前作答；课程进度记录上限 220 KB，容量满时先淘汰最旧历史。标记完成与测验得分独立，点击目录会保存当前课时。生成和评阅会将相应的需求、资料、课程和作答发送给所选模型。

进入课程后，AI 导师自动为当前课时创建或恢复专属 Chat，对话上下文包含本课内容，无需手动点击连接。导师使用宿主模型和历史管理，不拥有文件、网络、进程或业务工具权限。若恢复失败，可重试或显式新开对话；旧历史不会删除。

导师侧栏将页内引导折叠在聊天上方，展开后可定位学习目标、示例、知识要点自测和测验，并显示相应的分步提示。聊天区独立滚动，输入区留在侧栏底部。选择模型后，可一键请求 AI 给出下一步思考提示；模型的回答留在聊天中，不直接操纵页面。要点自测是应用实现的翻卡回忆组件，内容按纯文本呈现，不运行模型生成的 HTML 或脚本。

课程库支持搜索、移除课程，以及导入本应用课程结构的 JSON（最大 180 KB）。JSON 导入生成新课程 ID，不导入聊天或旧进度。每门课程可将可再次导入的课程内容 JSON 复制到剪贴板，不包含作答、项目或聊天；应用沙箱不提供文件下载。它不是 OpenMAIC ZIP、PPTX 或任意 JSON 导入器。移除操作需在卡片内再次确认，删除课程、学习进度及实训项目，历史聊天仍保留。

## 项目实训（PBL 文字版）

在课程编辑的第四步可选择是否添加项目实训。选择添加后，可手动创建项目草案，或让模型根据课程标题和各课学习目标生成项目情境、学习者角色、最终成果，以及 2–6 个阶段。每阶段包含目标、实践步骤、交付物说明和 1–5 条验收标准，预览通过校验后采用；采用后可在编辑区调整计划并保存。已有成果提交后，计划锁定以保留现有验收标准。课程学习页只展示已启用的项目，没有设计或编辑操作。当前版本只支持文字/代码文本成果，不上传文件、不执行代码、不自动访问网络，也不调度多人智能体。

每阶段可保存最多 6,000 字的成果草稿。切换阶段时保存当前草稿，离开实训前需点击「保存成果草稿」；再次进入恢复上次阶段与保存的文字。提交成果后可请求 AI 导师逐项评审，每次评审必须匹配项目、阶段及提交批次，并完整覆盖全部验收标准。格式错误、停止或调用失败时保留已提交成果，可重试。

评审结果显式采用后保存；全部标准满足后，由学习者点击「标记阶段完成」。AI 不会自动完成阶段，项目进度与课程阅读进度分别记录。修改草稿不改变已提交版本；再次提交则替换当前提交、清除该阶段旧评审与完成标记，其他阶段保留。当前只保留每阶段最新提交和评审，旧聊天仍在应用默认工作区的历史中。

项目采用后不会被重新生成覆盖。课程内容后续修改时，实训保留创建时的目标和已有成果，并提示课程已更新。移除课程会同时删除该课程的实训数据，聊天历史保留。

## 存储与边界

应用通过数据 SDK 写入自己的 `~/.isle-claw/apps/@isle/learning/storage.sqlite`；默认工作区位于同目录的 `workspace/`，生成、导师及评阅聊天位于该工作区的 `.isle-claw/chats/`。设置 `ISLE_SERVER_DATA_DIR` 时，根目录随之改变。无需 OpenMAIC 服务，也不写入宿主全局业务数据库。

当前仍是小型文本课程，每门课程独立保存：已完成课程上限 180 KB，暂存课程上限 240 KB，低于桥接请求的 256 KiB 限制。数据库读取逐门进行。课程采用版本 2，保留稳定课时 ID 和多题型数据。首次打开此版本时，应用会清空学习工作台旧版本的全部业务存储（包括课程、进度、项目、导师会话引用及旧暂存记录），并删除该应用名下的历史聊天会话，然后写入数据版本标记。后续打开不会再次清空新数据；旧数据不迁移、不兼容。

| 业务键                                 | 用途                                                      |
| -------------------------------------- | --------------------------------------------------------- |
| `learning:data-version`                | 当前数据版本标记                                          |
| `learning:course:<id>`                 | 版本 2 的暂存或已完成课程                                 |
| `learning:progress:<id>`               | 当前课时、完成列表、最近作答、历史作答、AI 评分与评阅会话 |
| `learning:tutor:<courseId>:<lessonId>` | 各课导师会话引用                                          |

暂存课程在自身的 `learning:course:<id>` 中保存当前创建步骤、需求、可编辑大纲、已完成课时、当前生成任务及其会话引用。实训键 `learning:pbl:<courseId>` 保存项目计划、来源目标、阶段成果、最新提交、评审、完成状态和会话引用；单个项目记录上限 220 KB。

工作区 SDK 只用于取得本应用的默认 Chat 工作区，凭据由宿主掌管。应用声明 `chat`、`application-workspaces`、`application-data`；场景工具白名单为空，Agent 进程能力关闭，其余能力未声明。UI 无需修改宿主 CSP。

存储失败明确显示错误；进度只在写入成功后更新。首次旧存储及历史会话清理成功后才会写入版本标记；清理失败会阻止课程库加载，重试时继续清理。清理完成后读取失败不会覆盖当前课程。课程结构拒绝非法答案、重复选项、超限字段和未知版本。模型文字按纯文本显示，不执行 HTML、脚本或远程资源。

## OpenMAIC 复用范围

参考版本：THU-MAIC/OpenMAIC `ebf665f316372d6ee875bd50dac1e04662d5a519`。

- 复用并适配 `lib/quiz/grading.ts`，位于应用的 `main/vendor/grading.ts`。保留精确选项匹配逻辑，支持单选、多选的精确答案匹配；简答单独通过 Isle Chat 评阅；MIT 版权与许可位于应用根目录 `LICENSE`，构建时一起分发。
- 采用课程分场景、学习目标、讲解、测验相结合的产品结构。课程 JSON、大纲与分课任务、生成提示词、界面、存储和 Isle Chat 接入由本应用实现。分课流程参考 OpenMAIC 的两阶段生成设计，尚未引入 `@openmaic/generation` 运行时。
- 没有引入 OpenMAIC 全站、Next.js 服务、生成 SDK 或完整课堂运行时。暂不包含 PPT 导入／编辑／导出、图片生成、语音、白板、生成式 HTML 实验和多人课堂；受控翻卡组件由 Isle 应用实现，PBL 仅参考角色、里程碑与交付物设计，实现文字实训，未迁移完整 PBL 运行时。

## 开发与验证

在仓库根目录执行：

```sh
pnpm install
pnpm --filter client build:chat-ui
pnpm --filter @isle/learning dev --port 5178
pnpm --filter @isle/learning build
pnpm --filter @isle/learning test
```

开发预览使用工具链提供的内存工作区和模拟聊天，顶部明确标示，刷新清空数据；模拟模型不会生成真实课程。AI 生成需要在实际 Isle 宿主中使用已配置模型验证。示例课程可完整体验阅读、测验和页面间进度恢复。

构建生成 `apps/applications/builtins/learning/dist/isle`，可作为 Isle 应用安装；`pnpm --filter @isle/builtin-applications build` 将其与其他内置应用一起打包。运行中的旧客户端需要重新构建／加载内置应用，单独构建本应用不会自动改动用户的安装目录。

测试覆盖课程结构、大小限制、最新一轮生成完成判定、失败与截断输出、判分、作答历史与局部修改校验、进度恢复、旧数据一次性清理、存储失败、幂等保存，以及安装包权限、许可和大小。存储测试使用 SDK 同形的内存适配器验证应用逻辑，不替代宿主数据库或真实模型端到端测试。

浏览器回归测试：先启动上面的开发预览，再在安装了 Playwright 的环境执行 `node apps/applications/builtins/learning/test/browser-smoke.mjs`。可通过 `PLAYWRIGHT_MODULE` 指定模块路径，通过 `CHROME_PATH` 指定浏览器，通过 `LEARNING_URL` 指定预览地址（默认 5178）。测试仅替换开发预览的模型输出，使用真实 UI、SDK 和预览 Chat 引擎，覆盖多文件文本导入、要点回忆与页内引导、作答历史与薄弱题重练、AI 局部修改、课程 JSON 复制、大纲预览和课时弹窗编辑、返回恢复、单课失败重试、多题型作答、AI 评分保存、单课重生成、PBL 评审/重交/恢复、项目删除与移动端布局；不访问真实模型或用户数据库。
