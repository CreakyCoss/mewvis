# 学习工坊

`@mewvis/learning` 是独立的 Mewvis 内置应用，源码位于 `apps/applications/builtins/learning`。
它使用公开的 `@mewvis/app-sdk` 聊天、数据和工作区接口，已登记在 `apps/applications/registry.json` 中，随内置应用构建打包；默认启用。

## 使用

在应用列表打开「学习工坊」，页面占满常驻导航栏之外的应用工作区，通过导航栏切换到其他页面。课程库的名称与课程总数收在顶栏，列表区提供导入、搜索与继续学习；首次进入时可从空状态打开示例课程，无需模型即可阅读三个课时、完成单选题并记录学习进度。课程卡片直接显示当前课时和进度，提供「编辑课程」，复制 JSON 与移除放在「更多」中。

「创建课程」和「编辑课程」使用全屏工作区，左侧按「课程设置 → 课程大纲 → 课时内容 → 项目实训」四步编辑，右侧的 AI 课程助手在四步中常驻。设置页直接填写主题、占满表单宽度的水平选择和默认可见的参考资料。大纲页直接编辑课程简介、学习目标和宏观学习路径，不展示或维护课时，也没有独立的编辑、取消或完成按钮。课时页以紧凑列表维护唯一一份课时数据；点击添加或已有课时后，左侧打开局部弹窗，分别在「课时信息」「教学内容」「动手实验」「课后测验」四个页签编辑。项目实训是独立的可选步骤，启用后在页面内直接编辑项目基础信息和实践阶段。内容修改只保存在本次编辑会话中；点击底部「暂存」会写入暂存课程并留在编辑页，点击左上角返回图标会丢弃未暂存的修改。至少完成一课后，可在第四步「保存课程」。暂存课程可从首页点击「继续编辑」恢复；保存后状态变为「已完成」。学习工作区的顶栏固定，目录、正文和 AI 导师各自滚动；导师默认常驻。

右侧 AI 课程助手的标题只显示图标与名称，作用范围在下一行以「当前内容 / 整个课程」切换；具体当前内容可从控件提示中查看。输入框底部左侧显示当前模型名称与下箭头，点击后展开模型列表；右下角是圆形发送按钮。点击推荐要求会直接发送。每轮要求、生成状态与结果预览按对话顺序保留；采用、查看、放弃或继续调整后，对应结果会显示状态。对话记录随课程暂存或保存，重新编辑时恢复，删除课程时一并清除。只有显式采用才会修改当前课程编辑内容。

### 课程编辑视觉规范

课程编辑区的字体与控件尺寸在 `main/styles.css` 的 `.learning-app` 设计变量中定义，四个步骤、课时列表、课时弹窗和右侧助手共用同一套层级。

| 用途 | 规范 |
| --- | --- |
| 字号 | 页面标题 20px、区块标题 16px、正文 14px、表单标签与小按钮 13px、辅助说明 12px；标题字重 650。 |
| 颜色 | 正文、卡片、边框和强调色使用宿主 `--foreground`、`--card`、`--border`、`--primary`；次要文字由正文色与卡片色混合，保证亮色和暗色主题下均易读。 |
| 间距 | 以 8px 为基本单位，常用 8 / 16 / 24px；桌面步骤内容左右留白 30px，窄屏为 18px。 |
| 控件 | 普通表单控件 40px；增删题目和阶段等就地操作按钮 34px，课时列表的常驻图标按钮 30px；窄屏主要按钮至少 40px；课程底部主要操作保持 40px。 |
| 交互 | 输入控件有可见边框和焦点状态；原生选择框统一使用自绘下拉箭头，保留键盘和系统选择菜单。测验题目的题型与删除位于题目抬头，题干、正确答案、解析依次排列。 |

课程工作台沿用四步格式。本次富内容扩展继续使用课程版本 2 与数据标记 `course-flow-v5`，不会触发数据清理；已有纯文本课程可继续阅读、编辑和保存。

「创建课程」接受主题、水平及可选参考资料。资料可以粘贴，或一次追加最多 5 个 UTF-8 TXT / Markdown 文件（每个文件上限 80 KB，合计文本上限 20,000 字）；导入文本标出文件名作为来源提示，不提供逐段引用。进入「课程大纲」后，直接在页面填写简介、学习目标和学习路径。右侧助手可依据当前步骤或整个课程生成建议；点击发送即开始生成，预览并采用后仍需点击「暂存」才会保存。

大纲可随时暂存未完成的填写内容；进入课时步骤前需完成大纲必填项。大纲不会预建课时。课时页负责添加和编辑课时；每节课右侧常驻上移、下移和移除图标，移除需再次确认（最终 1–8 课）。点击「添加课时」直接打开空白弹窗；只有完整课时通过必填校验并保存后才进入本次编辑会话的列表。点击已有课时可编辑全部内容，弹窗底部提供「取消」和「保存课时」；最终写入课程仍以底部「暂存」或「保存课程」为准。

课时弹窗打开时，右侧 AI 助手会跟随当前课时，可生成新课或优化已有课时；每次只处理一课，完成后预览并显式采用。格式错误、模型失败或停止不会覆盖其他已填写的课时。AI 建议采用后仍只进入本次编辑会话，关闭页面会丢弃未暂存的结果。所有课时准备完毕后，在项目实训步骤点击「保存课程」。保存重试复用同一个课程 ID。

课程卡片的「编辑课程」打开同一全屏工作区，直接加载课程数据，可以切换设置、大纲、课时或项目实训步骤。学习页不提供编辑入口。已完成课程在编辑页点击「保存」后保持已完成状态；直接关闭则保留上次保存的课程。暂存课程只能继续编辑，不能进入学习页。重做的课时获得新的内容 ID，其旧测验、完成状态和导师会话引用不再沿用；未改动课时保留原 ID 与学习进度。

课时弹窗支持修改标题、目标、正文、示例、知识要点，以及单选、多选和简答题的题干、分值、选项、答案、解析、评分标准。分值为 0.5–10 分，按 0.5 分递增；可添加/删除题目和选项，提交时使用与 AI 输出相同的校验规则。所有必填内容通过校验后才能保存；未修改内容的保存保留原课时 ID，内容变化则生成新 ID，以免旧测验和导师上下文附到修改后的内容。

已有课时可在右侧助手填写具体修改要求并直接发送。模型只返回要改的字段，应用将字段合并到原课时并按完整课时规则校验；未知字段和无实际变化的结果会被拒绝。预览并显式采用后更新当前编辑会话，暂存或保存课程后才会写入数据。内容变化会更新课时 ID，旧作答和导师上下文不会附到新内容。

学习页提供目录、正文、例子、要点，以及单选、多选、简答三种题型。选择题本地判分，多选必须完整匹配答案；简答题先保存作答，再点击「连接 AI 评阅」，选择模型开始评分。AI 按每题分值、参考答案和评分标准返回 0 至该题满分的得分及反馈，评分结果须匹配当前作答批次和全部简答题，通过校验后显式采用保存。AI 评分仅供学习参考，失败或停止不会抹掉已保存答案。

「全部再练」创建新的作答批次；如果有答错或未满分的题目，也可以「只练需巩固的题」，沿用上次已掌握题目的答案，重新填写需要巩固的题目。最近一次作答及历史记录显示“掌握参考”，按已评分题目的得分比例估算，并明确提示尚未评分的简答题；它不是跨课程能力诊断。每课保留当前作答及最多 8 条先前作答；课程进度记录上限 220 KB，容量满时先淘汰最旧历史。标记完成与测验得分独立，点击目录会保存当前课时。生成和评阅会将相应的需求、资料、课程和作答发送给所选模型。

进入课程后，AI 导师自动为当前课时创建或恢复专属 Chat，对话上下文包含本课内容，无需手动点击连接。导师使用宿主模型和历史管理，不拥有文件、网络、进程或业务工具权限。若恢复失败，可重试或显式新开对话；旧历史不会删除。

导师侧栏将页内引导折叠在聊天上方，展开后可定位学习目标、示例、知识要点自测和测验，并显示相应的分步提示。聊天区独立滚动，输入区留在侧栏底部。选择模型后，可一键请求 AI 给出下一步思考提示；模型的回答留在聊天中，不直接操纵页面。要点自测是应用实现的翻卡回忆组件，内容按纯文本呈现，不运行模型生成的 HTML 或脚本。

课程库支持搜索、移除课程，以及导入本应用课程结构的 JSON（最大 180 KB）。JSON 导入生成新课程 ID，不导入聊天或旧进度。每门课程可将可再次导入的课程内容 JSON 复制到剪贴板，不包含作答、项目或聊天；应用沙箱不提供文件下载。它不是 OpenMAIC ZIP、PPTX 或任意 JSON 导入器。移除操作需在卡片内再次确认，删除课程、学习进度及实训项目，历史聊天仍保留。

## 富内容课时与动手实验

课程库顶栏提供「函数实验示例」，包含四节课。第二课可直接体验公式、流程图和函数图像实验；此入口仅在没有该示例时创建课程，已有课程不会被覆盖。

教学内容由最多 20 个内容块组成：Markdown 正文、LaTeX 公式、流程图、代码示例和提示。支持添加、复制、上下移动、删除及预览；图解可编辑 2–8 个节点的文字和说明，切换水平或垂直方向。代码仅展示。具体示例、知识要点、测验沿用原有字段。点击「保存课时」更新本次编辑会话，再点击课程底部「保存」或「保存课程」写入存储。

在「动手实验」启用函数图像模板 `linear-function`，配置固定公式 `y = kx + b` 的参数范围、步长、初始值、目标点、允许误差、提示与成功反馈。参数及目标坐标限 -100–100；参数最多 6 位小数，步长至少 0.01，最多 2,000 步，范围须被步长整除。保存和 AI 采用前校验离散参数组合能否到达目标，防止不可完成的任务。无效配置保留在表单并显示错误，暂停试跑。

学习页的「动手实验」与课程讲解、测验并列，提供图像、滑块、重置、检查和提示。检查按 `abs(k*x+b-y) <= tolerance` 本地计算，写入成功后显示反馈；仅保存每课最近一次检查的参数和时间，不自动标记课时完成、不计入测验分数。重置只重置当前参数，未检查的操作不覆盖已保存记录。作者的学生预览不写学习记录。窄屏实验台将导师折叠为入口，可展开或把当前参数发送给导师请求引导。

`Lesson.blocks` 和 `Lesson.experiment` 为可选字段；存在内容块时 `content` 由结构化块生成，供导师、评分和旧文本消费者读取，避免两份正文不一致。导入、复制 JSON、草稿、AI 生成和局部修改均支持这两个字段。旧课时未修改时保持原 ID；实际修改仍沿用现有机制更换该课时 ID，避免旧测验、实验记录和导师上下文绑定到新内容，其他课时保留。

AI 以当前表单快照和编辑页签为上下文，建议仍需显式采用。富内容正文必须通过完整 `blocks` 数组修改；`experiment: null` 表示移除实验。生成期间继续修改或关闭课时表单时，拒绝采用旧建议，要求重新生成，保护未保存的手动编辑。

公式和 Markdown 依赖打包在应用内；图解由结构化节点渲染，函数图像由 Canvas 绘制。没有新增宿主权限、嵌入视图声明、外部请求或脚本执行能力。应用 JavaScript 包预算由 512 KiB 调整为 768 KiB，以容纳本地数学与 Markdown 渲染器。

## 项目实训（PBL 文字版）

在课程编辑的第四步可选择是否添加项目实训。选择添加后，直接在页面编辑项目情境、学习者角色、最终成果及 2–6 个可展开的实践阶段；也可让右侧助手生成项目方案，预览通过校验后采用。每阶段包含目标、实践步骤、交付物说明和 1–5 条验收标准。未完成的项目方案可以随课程暂存；保存已完成课程时须通过完整校验。已有成果提交后，计划锁定以保留现有验收标准。课程学习页只展示已启用的项目，没有设计或编辑操作。当前版本只支持文字/代码文本成果，不上传文件、不执行代码、不自动访问网络，也不调度多人智能体。

每阶段可保存最多 6,000 字的成果草稿。切换阶段时保存当前草稿，离开实训前需点击「保存成果草稿」；再次进入恢复上次阶段与保存的文字。提交成果后可请求 AI 导师逐项评审，每次评审必须匹配项目、阶段及提交批次，并完整覆盖全部验收标准。格式错误、停止或调用失败时保留已提交成果，可重试。

评审结果显式采用后保存；全部标准满足后，由学习者点击「标记阶段完成」。AI 不会自动完成阶段，项目进度与课程阅读进度分别记录。修改草稿不改变已提交版本；再次提交则替换当前提交、清除该阶段旧评审与完成标记，其他阶段保留。当前只保留每阶段最新提交和评审，旧聊天仍在应用默认工作区的历史中。

项目采用后不会被重新生成覆盖。课程内容后续修改时，实训保留创建时的目标和已有成果，并提示课程已更新。移除课程会同时删除该课程的实训数据，聊天历史保留。

## 存储与边界

应用通过数据 SDK 写入自己的 `~/.mewvis/apps/@mewvis/learning/storage.sqlite`；默认工作区位于同目录的 `workspace/`，生成、导师及评阅聊天位于该工作区的 `.mewvis/chats/`。设置 `MEWVIS_SERVER_DATA_DIR` 时，根目录随之改变。无需 OpenMAIC 服务，也不写入宿主全局业务数据库。

当前支持小型富内容课程，每门课程独立保存：已完成课程上限 180 KB，暂存课程上限 240 KB，低于桥接请求的 256 KiB 限制。数据库读取逐门进行。课程采用版本 2，保留稳定课时 ID 和多题型数据。历史四步工作台升级首次写入 `course-flow-v5` 标记时，会清空更早的学习工坊业务存储（包括课程、进度、项目、导师会话引用及旧暂存记录），并删除该应用名下的历史聊天会话，然后写入数据版本标记。后续打开不会再次清空新数据；旧数据不迁移、不兼容。

| 业务键                                 | 用途                                                      |
| -------------------------------------- | --------------------------------------------------------- |
| `learning:data-version`                | 当前数据版本标记                                          |
| `learning:course:<id>`                 | 版本 2 的暂存或已完成课程                                 |
| `learning:progress:<id>`               | 当前课时、完成列表、测验作答与评分、最近实验检查 |
| `learning:tutor:<courseId>:<lessonId>` | 各课导师会话引用                                          |

暂存课程在自身的 `learning:course:<id>` 中保存当前创建步骤、需求、可编辑大纲、已完成课时、当前生成任务及其会话引用。实训键 `learning:pbl:<courseId>` 保存项目计划、来源目标、阶段成果、最新提交、评审、完成状态和会话引用；单个项目记录上限 220 KB。

工作区 SDK 只用于取得本应用的默认 Chat 工作区，凭据由宿主掌管。应用声明 `chat`、`application-workspaces`、`application-data`；场景工具白名单为空，Agent 进程能力关闭，其余能力未声明。UI 无需修改宿主 CSP。

存储失败明确显示错误；进度只在写入成功后更新。首次旧存储及历史会话清理成功后才会写入版本标记；清理失败会阻止课程库加载，重试时继续清理。清理完成后读取失败不会覆盖当前课程。课程结构拒绝非法答案、重复选项、超限字段和未知版本。正文支持安全 Markdown，公式使用本地 KaTeX 转为 MathML；不执行 HTML、脚本或加载远程图片。

## OpenMAIC 复用范围

参考版本：THU-MAIC/OpenMAIC `ebf665f316372d6ee875bd50dac1e04662d5a519`。

- 复用并适配 `lib/quiz/grading.ts`，位于应用的 `main/vendor/grading.ts`。保留精确选项匹配逻辑，支持单选、多选的精确答案匹配；简答单独通过 Mewvis Chat 评阅；MIT 版权与许可位于应用根目录 `LICENSE`，构建时一起分发。
- 采用课程分场景、学习目标、讲解、测验相结合的产品结构。课程 JSON、大纲与分课任务、生成提示词、界面、存储和 Mewvis Chat 接入由本应用实现。分课流程参考 OpenMAIC 的两阶段生成设计，尚未引入 `@openmaic/generation` 运行时。
- 没有引入 OpenMAIC 全站、Next.js 服务、生成 SDK 或完整课堂运行时。暂不包含 PPT 导入／编辑／导出、图片生成、语音、白板、生成式 HTML 实验和多人课堂；受控翻卡组件由 Mewvis 应用实现，PBL 仅参考角色、里程碑与交付物设计，实现文字实训，未迁移完整 PBL 运行时。

## 开发与验证

在仓库根目录执行：

```sh
pnpm install
pnpm --filter client build:chat-ui
pnpm --filter @mewvis/learning dev --port 5178
pnpm --filter @mewvis/learning build
pnpm --filter @mewvis/learning test
```

开发预览使用工具链提供的内存工作区和模拟聊天，顶部明确标示，刷新清空数据；模拟模型不会生成真实课程。AI 生成需要在实际 Mewvis 宿主中使用已配置模型验证。示例课程可完整体验阅读、测验和页面间进度恢复。
