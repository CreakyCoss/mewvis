# 学习工作台

`@isle/learning` 是独立的 Isle 内置应用，源码位于 `apps/applications/builtins/learning`。
它使用公开的 `@isle/app-sdk` 聊天、数据和工作区接口，随内置应用构建自动发现；默认启用。

## 使用

在应用列表打开「学习工作台」，默认进入应用全屏，可通过宿主提供的按钮退出或重新进入全屏。无需模型即可打开示例课程，阅读三个课时、完成单选题并记录学习进度。

「创建课程」接受主题、水平、3–8 个计划课时，以及可选参考资料。资料可以粘贴，或导入 UTF-8 TXT / Markdown（文件上限 80 KB，文本上限 20,000 字）。保存需求后，点击「准备生成大纲」，在宿主 Chat 中选择模型并开始生成。

大纲通过校验后，点击「采用并保存结果」。可以修改课程名称、简介、每课标题与目标，调整顺序、添加和移除课时（最终 1–8 课）。手动编辑后点击「保存大纲修改」；启动单课生成也会保存当前大纲。修改已生成课时的标题或目标会清除该课的草稿内容，需要重新生成；正式课程不受影响。

点击「生成本课」或「生成下一个待完成课时」，每次只生成一课，完成后预览并采用。格式错误、模型失败或停止时，已采用的其他课时保留；可在原会话重试或要求修正 JSON。任务会话引用和已采用内容保存到应用数据库，离开工坊后可以恢复。未发送的空会话不保证跨宿主重启恢复，连接失败时可新建会话重试。所有课时准备完毕后，点击「保存课程，开始学习」。保存重试复用同一个课程 ID。

已保存课程顶部的「编辑 / 重新生成」进入同一工坊，可以只重做某一课。生成结果先写入草稿，保存课程后才替换正式内容。重做的课时获得新的内容 ID，其旧测验、完成状态和导师会话引用不再沿用；未改动课时保留原 ID 与学习进度。历史聊天仍保留。如果已有其他课程的草稿，先完成或显式放弃该草稿。旧版整课生成草稿保留「继续旧版生成」入口。

工坊中每个课时的「手动编辑内容」支持直接修改标题、目标、正文、示例、知识要点，以及单选、多选和简答题的题干、选项、答案、解析、评分标准。可添加/删除题目和选项，提交时使用与 AI 输出相同的校验规则。保存到草稿后，再保存课程才会更新课程库；未修改内容的保存保留原课时 ID，内容变化则生成新 ID，以免旧测验和导师上下文附到修改后的内容。

学习页提供目录、正文、例子、要点，以及单选、多选、简答三种题型。选择题本地判分，多选必须完整匹配答案；简答题先保存作答，再点击「连接 AI 评阅」，选择模型开始评分。AI 按参考答案和评分标准返回每题 0–1 分及反馈，评分结果须匹配当前作答批次和全部简答题，通过校验后显式采用保存。AI 评分仅供学习参考，失败或停止不会抹掉已保存答案。

「再练一次」创建新的作答批次；提交后替换本课之前的作答与评分。标记完成与测验得分独立，点击目录会保存当前课时。生成和评阅会将相应的需求、资料、课程和作答发送给所选模型。

「连接 AI 导师」为当前课程的当前课时创建或恢复专属 Chat，对话上下文包含本课内容。导师使用宿主模型和历史管理，不拥有文件、网络、进程或业务工具权限。空会话在重启后若无法恢复，可显式新开对话；旧历史不会删除。

课程库支持搜索、移除课程，以及导入本应用课程结构的 JSON（最大 180 KB）。JSON 导入生成新课程 ID，不导入聊天或旧进度。它不是 OpenMAIC ZIP、PPTX 或任意 JSON 导入器。移除操作需在卡片内再次确认，删除课程、学习进度及实训项目，历史聊天仍保留。

## 项目实训（PBL 文字版）

课程页的「项目实训」为每门课程保存一个项目。点击「设计实训项目」，模型根据创建时的课程标题和各课学习目标生成项目情境、学习者角色、最终成果，以及 2–6 个阶段。每阶段包含目标、实践步骤、交付物说明和 1–5 条验收标准，预览通过校验后采用。当前版本只支持文字/代码文本成果，不上传文件、不执行代码、不自动访问网络，也不调度多人智能体。

每阶段可保存最多 6,000 字的成果草稿。切换阶段时保存当前草稿，离开实训前需点击「保存成果草稿」；再次进入恢复上次阶段与保存的文字。提交成果后可请求 AI 导师逐项评审，每次评审必须匹配项目、阶段及提交批次，并完整覆盖全部验收标准。格式错误、停止或调用失败时保留已提交成果，可重试。

评审结果显式采用后保存；全部标准满足后，由学习者点击「标记阶段完成」。AI 不会自动完成阶段，项目进度与课程阅读进度分别记录。修改草稿不改变已提交版本；再次提交则替换当前提交、清除该阶段旧评审与完成标记，其他阶段保留。当前只保留每阶段最新提交和评审，旧聊天仍在应用默认工作区的历史中。

项目采用后不会被重新生成覆盖。课程内容后续修改时，实训保留创建时的目标和已有成果，并提示课程已更新。移除课程会同时删除该课程的实训数据，聊天历史保留。

## 存储与边界

应用通过数据 SDK 写入自己的 `~/.isle-claw/apps/@isle/learning/storage.sqlite`；默认工作区位于同目录的 `workspace/`，生成、导师及评阅聊天位于该工作区的 `.isle-claw/chats/`。设置 `ISLE_SERVER_DATA_DIR` 时，根目录随之改变。无需 OpenMAIC 服务，也不写入宿主全局业务数据库。

当前仍是小型文本课程，每门课程独立保存，上限 180 KB；生成草稿上限 240 KB，低于桥接请求的 256 KiB 限制。数据库读取逐门进行。新课程保存为版本 2，保留稳定课时 ID 和多题型数据；版本 1 课程继续读取，进入工坊保存后升级，不做破坏性批量迁移。

| 业务键                                 | 用途                                            |
| -------------------------------------- | ----------------------------------------------- |
| `learning:course:<id>`                 | 版本 1 / 2 的课程文档                           |
| `learning:progress:<id>`               | 当前课时、完成列表、最近作答、AI 评分与评阅会话 |
| `learning:draft:v1`                    | 旧版整课生成记录（兼容保留）                    |
| `learning:tutor:<courseId>:<lessonId>` | 各课导师会话引用                                |

新版草稿键 `learning:draft:v2` 保存需求、可编辑大纲、已完成课时、当前生成任务及其会话引用。实训键 `learning:pbl:<courseId>` 保存项目计划、来源目标、阶段草稿、最新提交、评审、完成状态和会话引用；单个项目记录上限 220 KB。

工作区 SDK 只用于取得本应用的默认 Chat 工作区，凭据由宿主掌管。应用声明 `chat`、`application-workspaces`、`application-data`；场景工具白名单为空，Agent 进程能力关闭，其余能力未声明。UI 无需修改宿主 CSP。

存储失败明确显示错误；进度只在写入成功后更新。损坏的课程保留原值并单独报告，读取失败不会初始化空库或覆盖原数据。课程结构拒绝非法答案、重复选项、超限字段和未知版本。模型文字按纯文本显示，不执行 HTML、脚本或远程资源。

## OpenMAIC 复用范围

参考版本：THU-MAIC/OpenMAIC `ebf665f316372d6ee875bd50dac1e04662d5a519`。

- 复用并适配 `lib/quiz/grading.ts`，位于应用的 `main/vendor/grading.ts`。保留精确选项匹配逻辑，支持单选、多选的精确答案匹配；简答单独通过 Isle Chat 评阅；MIT 版权与许可位于应用根目录 `LICENSE`，构建时一起分发。
- 采用课程分场景、学习目标、讲解、测验相结合的产品结构。课程 JSON、大纲与分课任务、生成提示词、界面、存储和 Isle Chat 接入由本应用实现。分课流程参考 OpenMAIC 的两阶段生成设计，尚未引入 `@openmaic/generation` 运行时。
- 没有引入 OpenMAIC 全站、Next.js 服务、生成 SDK 或完整课堂运行时。暂不包含 PPT 导入／编辑／导出、图片生成、语音、白板、HTML 实验和多人课堂；PBL 仅参考角色、里程碑与交付物设计，实现文字实训，未迁移完整 PBL 运行时。

## 开发与验证

在仓库根目录执行：

```sh
pnpm install
pnpm --filter client build:chat-ui
pnpm --filter @isle/learning dev --port 5178
pnpm --filter @isle/learning build
pnpm --filter @isle/learning test
```

开发预览使用工具链提供的内存工作区和模拟聊天，顶部明确标示，刷新清空数据；模拟模型不会生成真实课程。AI 生成需要在实际 Isle 宿主中使用已配置模型验证。示例课程可完整体验阅读、测验和页面间进度恢复。

构建生成 `apps/applications/builtins/learning/dist/isle`，可作为 Isle 应用安装；`pnpm --filter @isle/builtin-applications build` 将其与其他内置应用一起打包。运行中的旧客户端需要重新构建／加载内置应用，单独构建本应用不会自动改动用户的安装目录。

测试覆盖课程结构、大小限制、最新一轮生成完成判定、失败与截断输出、判分、进度恢复、损坏文档保留、存储失败、幂等保存，以及安装包权限、许可和大小。存储测试使用 SDK 同形的内存适配器验证应用逻辑，不替代宿主数据库或真实模型端到端测试。

浏览器回归测试：先启动上面的开发预览，再在安装了 Playwright 的环境执行 `node apps/applications/builtins/learning/test/browser-smoke.mjs`。可通过 `PLAYWRIGHT_MODULE` 指定模块路径，通过 `CHROME_PATH` 指定浏览器，通过 `LEARNING_URL` 指定预览地址（默认 5178）。测试仅替换开发预览的模型输出，使用真实 UI、SDK 和预览 Chat 引擎，覆盖大纲编辑、返回恢复、单课失败重试、多题型作答、AI 评分保存、单课重生成、PBL 评审/重交/恢复、手动内容编辑、项目删除与移动端布局；不访问真实模型或用户数据库。
