# 学习工作台

`@isle/learning` 是独立的 Isle 内置应用，源码位于 `apps/applications/builtins/learning`。
它使用公开的 `@isle/app-sdk` 聊天、数据和工作区接口，随内置应用构建自动发现；默认启用。

## 使用

在应用列表打开「学习工作台」。无需模型即可打开示例课程，阅读三个课时、完成单选题并记录学习进度。

「创建课程」接受学习主题、水平、3–8 个课时，以及可选的参考资料。资料可以粘贴，或从本地选择 UTF-8 的 TXT / Markdown 文件（文件上限 80 KB，文本上限 20,000 字）。点击下一步，在宿主 Chat 中选择已配置的模型，再点击「生成完整课程」。主题和参考资料会发送给该模型。

生成结束后，应用校验完整课程 JSON，显示课程简介和各课目标。点击「加入课程库，开始学习」保存课程。若输出不完整或结构无效，原对话保留，可继续要求模型修正；不会把失败结果当成课程。可通过聊天停止生成，通过「结束此生成，重新填写需求」关闭本次会话并回到表单。已发送的生成对话及其需求可在重新打开工坊时恢复。未发送的空会话不保证跨宿主重启恢复；失败时保留需求供重新创建。

学习页提供目录、正文、具体例子、要点和单选测验。提交后展示正确答案与解释；可再次练习，最新一次提交替换该课此前结果。标记完成与测验得分相互独立，允许按自己的节奏学习。点击目录会保存当前课时。

「连接 AI 导师」为当前课程的当前课时创建或恢复专属 Chat，对话上下文包含本课内容。导师使用宿主模型和历史管理，不拥有文件、网络、进程或业务工具权限。空会话在重启后若无法恢复，可显式新开对话；旧历史不会删除。

课程库支持搜索、移除课程，以及导入本应用课程结构的 JSON（最大 180 KB）。JSON 导入生成新课程 ID，不导入聊天或旧进度。它不是 OpenMAIC ZIP、PPTX 或任意 JSON 导入器。移除操作需在卡片内再次确认，只删除课程和学习进度，历史聊天仍保留。

## 存储与边界

基础版只保存小型文本课程，因此使用应用数据 SDK，无需额外数据库或 OpenMAIC 服务。每门课程独立存储，控制在 180 KB 内；总库读取逐项进行，以适配桥的单次请求和响应限制。

| 业务键                                 | 用途                             |
| -------------------------------------- | -------------------------------- |
| `learning:course:<id>`                 | 版本为 1 的课程文档              |
| `learning:progress:<id>`               | 当前课时、完成列表、最近答题结果 |
| `learning:draft:v1`                    | 当前生成会话引用与学习需求       |
| `learning:tutor:<courseId>:<lessonId>` | 各课导师会话引用                 |

工作区 SDK 只用于取得本应用的默认 Chat 工作区，凭据由宿主掌管。应用声明 `chat`、`application-workspaces`、`application-data`；场景工具白名单为空，Agent 进程能力关闭，其余能力未声明。UI 无需修改宿主 CSP。

存储失败明确显示错误；进度只在写入成功后更新。损坏的课程保留原值并单独报告，读取失败不会初始化空库或覆盖原数据。课程结构拒绝非法答案、重复选项、超限字段和未知版本。模型文字按纯文本显示，不执行 HTML、脚本或远程资源。

## OpenMAIC 复用范围

参考版本：THU-MAIC/OpenMAIC `ebf665f316372d6ee875bd50dac1e04662d5a519`。

- 复用并适配 `lib/quiz/grading.ts`，位于应用的 `main/vendor/grading.ts`。保留精确选项匹配逻辑，基础版仅允许单选题；MIT 版权与许可位于应用根目录 `LICENSE`，构建时一起分发。
- 采用课程分场景、学习目标、讲解、测验相结合的产品结构。课程 JSON、生成提示词、界面、存储和 Isle Chat 接入由本应用实现。
- 没有引入 OpenMAIC 全站、Next.js 服务、生成 SDK 或完整课堂运行时。暂不包含 PPT 导入／编辑／导出、图片生成、语音、白板、HTML 实验、多人课堂、PBL 和简答题 AI 评分。

## 开发与验证

在仓库根目录执行：

```sh
pnpm install
pnpm --filter client build:chat-ui
pnpm --filter @isle/learning dev --port 5178
pnpm --filter @isle/learning build
pnpm --filter @isle/learning test
```

开发预览使用工具链提供的内存工作区和模拟聊天，顶部明确标示，刷新清空数据；模拟模型不会生成真实课程。AI 生成需要在实际 Isle 宿主中使用已配置模型验证。示例课程可完整体验阅读、测验和页面间进度恢复。

构建生成 `apps/applications/builtins/learning/dist/isle`，可作为 Isle 应用安装；`pnpm --filter @isle/builtin-applications build` 将其与其他内置应用一起打包。运行中的旧客户端需要重新构建／加载内置应用，单独构建本应用不会自动改动用户的安装目录。

测试覆盖课程结构、大小限制、最新一轮生成完成判定、失败与截断输出、判分、进度恢复、损坏文档保留、存储失败、幂等保存，以及安装包权限、许可和大小。存储测试使用 SDK 同形的内存适配器验证应用逻辑，不替代宿主数据库或真实模型端到端测试。
