# 影视工坊

影视工坊位于 `apps/applications/builtins/film-workshop`，应用 ID 为 `@mewvis/film-workshop`。默认启用，在故事工坊之后显示。首版围绕影视项目的创作流程实现业务，复用现有应用 SDK，不扩展宿主协议。

## 创作流程

借鉴 [AID Studio](https://github.com/gzxx-2025/aid-studio) 的七步流程：项目设定 → 剧本创作 → 素材准备 → 分镜设计 → 视频生成 → 音画同步 → 预览导出。漫剧、短剧、电影与静态漫画共用工作台，静态漫画的音视频步骤可跳过。

当前提供：

- 以最近项目和「继续创作」为主的首页，其他作品使用紧凑列表；继续入口恢复上次分集、步骤与镜头，新项目直接进入项目设定。
- 首页与工作台的七步流程始终单行，隐藏滚动条；空间不足时显示左右箭头，点击移动步骤栏，到达边缘时禁用对应方向。打开项目、切换步骤或改变工作区宽度时，自动把当前步骤移到可见位置。底部常驻前后步骤切换。
- 使用紧凑的字号层级：页面与镜头标题 22px，栏标题 16px，正文与控件 13px，辅助信息 11–12px；助手输入框按故事工坊使用 14px 字号，控件与留白同步收紧。
- 创作助手默认在右侧展开，窄屏通过侧边按钮展开面板；中间只编辑当前镜头，助手上下文包含选中镜头 ID。
- 作品库、新建、搜索、删除和 JSON 导入；导入总是创建独立副本，重建实体 ID 与引用，保留现有项目。
- 项目方向、比例、视觉风格与故事梗概；分集新增、重命名和删除，至少保留一个分集。
- 分集剧本编辑，以及 TXT / Markdown 导入；已有剧本提供追加或替换选择。
- 项目共享的角色、场景与道具设定，支持导入图片、视频、音频、PDF 和文本参考文件，并通过宿主预览。
- 分镜画面、景别、运镜、时长、角色和场景引用；镜头重排、删除，图片提示词与文件备注。分镜支持本地图片导入、生图和多版本选择。
- 按镜头生成视频和角色配音，编辑视频提示词、音色和声音设计，配音台词引用分镜内容；视频与音频支持导入、预览和独立的当前版本选择。
- 按镜头选择画面与配音，生成低清预览或导出 720p / 1080p MP4；提供进度、停止、合成历史与单一播放器。
- 制作时间轴、计划检查、Markdown 制作清单与项目 JSON 复制。
- 通过 Chat SDK 连接的创作助手，按项目与分集恢复会话，提供剧本、素材与分镜的结构化建议、媒体生成和计划检查。

示例「雨夜电台」只有在用户主动打开时创建，包含手工编写的剧本、素材与分镜，不模拟生成任务或媒体结果。七步导航为固定步骤视图，尚非可自由编辑的节点画布。

首页封面与示例分镜使用随应用打包的插图，并标注「创作示意」「分镜示意」。它们不属于用户生成的媒体，也不会写入项目 JSON。普通镜头显示文字分镜，文件备注不会被误用为图片预览。

## 持久化与边界

创建项目时选择工作目录，通过 `@mewvis/app-sdk/data` 注册应用工作区，在所选目录中创建 `film-projects/<projectId>/`：

- `project.json`：剧本、素材引用、镜头和生成记录。
- `media/`：分块导入的本地素材。
- `generated/<generationId>/`：每次图片、视频或配音生成的独立输出。
- `previews/<renderId>.mp4`、`exports/<renderId>.mp4`：每次合成的独立预览和成片。

`film:project:<id>` 只保存工作区索引，媒体路径使用项目内相对路径，不在 JSON 中保存二进制或临时预览地址。旧项目仍可打开，选择工作目录后迁移为文件存储。JSON 导入创建独立的文字计划副本，不复制原项目的媒体文件。

助手索引使用 `film:assistant:v2:<projectId>:<episodeId>:<workspaceId>`，绑定项目工作区；旧项目保留原助手索引。删除项目只移除作品库索引和导航位置，项目文件、素材和历史会话保留。解除素材关联也保留磁盘文件。

助手标题右侧为「会话历史」和「新建会话」。历史按当前项目与分集筛选，显示创建时间并标记当前会话；遵循宿主规则，发送消息后才生成历史记录。新建保留旧记录，切换后保存当前会话引用。发送、回复和切换期间禁用会话操作，创建或切换失败保留当前会话与草稿。面板收起由侧边「助手」入口控制。

导航位置独立保存在 `film:view:<projectId>`，不改变版本 1 的可移植项目格式。删除项目会同时删除其导航位置。失效的分集／镜头引用会回退到项目内有效实体；没有历史位置的项目按现有内容选择起始步骤。

项目格式为 `mewvis-film-project`，版本为 `1`。读取与导入校验格式版本、唯一 ID、素材类型、引用、时长、数组及文本上限；异常数据保留并明确报错，不自动重置或清空库。删除素材会解除所有分集中的对应引用，保留画面与台词。

页面编辑在 650 ms 后自动保存，写入按顺序执行；显示成功仅表示 SDK 写入已完成。手动保存、快捷键 Ctrl/Cmd+S 和返回作品库均执行保存，返回等待最新更改提交。保存失败保留页面草稿并显示错误，修正后可重试。快速关闭窗口前应确认显示「已保存」。首版未实现多窗口同项目冲突合并。

工作目录项目允许最大 16 MiB 的 JSON，素材通过文件 SDK 按 64 KiB 分块导入，文件大小不受业务存储的 JSON 限制。尚未选择工作目录的旧项目保留 220 KiB 的存储上限。文件备注不能作为生成成功或成片完成证据，制作计划检查通过只说明文字计划准备就绪。复制通过 SDK，需要用户操作。

助手的剧本、素材和分镜建议通过工具提交，用户在界面预览后按项采用；镜头媒体由专用按钮发起，图片、视频和配音的回填由工坊管理。小项目上下文包含完整数据，大项目提供有界摘要并明确标记，不能将截取的镜头当成完整计划检查。回复期间的项目修改等待会话空闲后同步，不打断当前回复。有工作目录的项目使用其注册工作区，旧项目暂用应用默认工作区；仅确认「未找到聊天记录」时重建空会话，其他连接错误保留引用并允许重试。

应用声明 `application-data`、`application-workspaces`、`workspace-files` 和 `chat`。Agent 仅可在当前工作区读写文件，允许访问所选模型及媒体输出所需的网络，仍受宿主权限及沙箱约束，不允许执行子进程。助手工具范围为 `film_check_delivery`、`film_propose_changes` 与 `generate_media`。模型、凭据和生成能力全部沿用宿主当前选中模型，不读取其他应用私有存储。

## 镜头媒体生成与回填

分镜图片、镜头视频和角色配音共用生成记录与结果回填流程，分别使用 `image-generation`、`video-generation`、`speech` 用途。按钮和助手对话都使用 `film_prepare_media` 登记目标，再调用 `generate_media` 生成。对话中明确指定的镜头优先，否则使用发送时选中的镜头；目标不明确时先通过 `ask_user` 确认。每次生成都追加素材并保留已有版本；首次生成默认选中，后续生成不替换当前选择，用户可点击素材版本切换或手动解除不需要的素材关联。每种媒体保留独立当前版本，生成期间用户切换或清除的选择不会被覆盖；未登记的聊天文件不会猜测归属。旧图片生成记录缺失用途时按图片读取。

视频优先将当前分镜图作为首帧；没有首帧时使用文字生成，参数由助手按当前模型的用途 Schema 解析。配音原样朗读用户确认的台词，音色备注不能直接作为供应商音色 ID。缺少台词、音色或模型不支持指定参数时，助手调用 `ask_user` 等待用户选择并继续当前任务，回答只覆盖本次生成，不修改全局模型设置。生成失败或停止后的付费重试必须先询问并得到明确授权，再递增 `attempt` 登记新的输出目录。背景音乐、自由音轨编辑与字幕仍未接入。

## 预览与成片导出

预览导出使用[宿主媒体处理 SDK](../media.md)，按当前分集的镜头顺序合成。画面默认选中当前视频，没有视频时使用当前分镜图；配音默认使用当前配音，可在时间轴逐镜头更换或关闭。此处的选择仅作用于本次合成，不改变生成页面的当前素材版本。镜头时长沿用分镜设置，支持完整留边或裁切铺满；无独立配音时默认保留视频原声。视频不足时长、配音超过片段时长默认失败，勾选对应选项后才允许末帧定格或音频裁剪。

主区为播放器与当前片段属性，下方按镜头时长排列画面、配音双轨。点击片段选择镜头，已合成且与当前配置一致时同时跳转到对应时间；播放和时间尺定位保持同步。配音波形来自实际音频解码，短音频后半段显示静音；解码不可用时只显示「波形不可用」，不影响合成。波形读取限制为单文件 8 MiB、10 分钟及双声道，串行解码并只缓存峰值。

更换素材、修改时长或合成策略后显示「预览待更新」，此时仍可观看历史视频，但暂停时间轴定位，重新生成后恢复同步。时间轴暂不支持拖动剪辑或重叠混音。导出设置与历史版本分别收进底部设置面板和标题旁版本菜单；进入此步骤默认收起助手，仍可从右侧重新打开。原声可逐片段选择，使用独立配音时替代该片段原声。

预览使用 360p，正式导出支持 720p / 1080p、24 / 30 fps，画幅继承项目比例。每次提交前保存项目及包含相对路径的合成快照，后续编辑不改变已提交任务。结果追加至 `project.json` 的 `renders`，保存宿主任务 ID、状态和输出信息，历史文件不覆盖。页面共用一个播放器，选择记录即可切换；移除记录需二次确认，只移除项目索引，保留磁盘成片。JSON 导入副本不携带合成任务与结果。

关闭页面不会停止宿主任务；重新打开后根据任务 ID 查询结果，网络失败可重新连接。提交结果未知时保留原请求 ID 与快照，用户点击「确认任务」后以同一请求确认，避免重复合成。失败或停止后不自动重试。宿主需要安装 FFmpeg/FFprobe，不可用时禁用合成并展示原因。尚未选择工作目录或缺少镜头画面时禁用提交。

填写镜头画面或图片提示词后，点击「生成分镜图片」。工坊先保存项目和请求记录，再向当前分集的助手会话提交一次生成请求。生成使用当前模型的 `image-generation` 配置，比例、视觉风格和关联角色／场景描述随请求传递。失败和停止后不自动重新提交付费请求。

生成记录固定项目、分集、镜头、会话及输出子目录，结果只从对应会话轮次的 `generate_media` 结构化结果提取。按钮通过生成标识定位轮次，对话通过 `film_prepare_media` 返回的任务 ID 定位；同一轮多个镜头的产物按独立输出目录分流。登记索引存放于应用存储 `film:media-request:<projectId>:…`，编辑器自动发现并保存到项目，应用工具不直接改写项目 JSON。回填前校验路径和文件存在，按路径去重。切换镜头不会改变回填目标；目标删除后仍保留媒体文件，不绑定其他镜头。

助手使用 v5 工具配置，启用 `ask_user` 和 `film_prepare_media`。旧会话保留在历史中，升级创建新会话时保留所选模型、思考等级与权限模式。询问时自动展开助手；停止操作按具体生成任务定位，取消回答且未生成媒体时记录为已停止。

应用工具由 Server 的应用宿主执行，使用与页面相同、按应用隔离的文件和数据连接。应用宿主提供工具和技能清单，Agent 只接收声明，并通过 stdio 请求当前任务授权的应用工具。Agent 不加载应用入口，也不需要读取应用数据库目录。文件访问仍由宿主统一校验。

界面提供进度、停止和重新连接。项目重新打开时恢复对未结束请求的监听，不重新发起生成。停止调用宿主会话的停止能力；上游是否取消由宿主和供应商决定，工坊不会声称已退费或已取消供应商账单。关闭工坊后宿主任务可以继续运行，再次打开后恢复结果关联。

## 助手结构化建议

在助手中要求打磨剧本、提取角色／场景／道具、拆分分镜或优化镜头，助手通过 `film_propose_changes` 提交建议。助手区显示「预览建议」，预览中可勾选需要采用的项目，更新字段同时显示当前内容与建议内容。未采用的项目继续保留，也可忽略整份建议。普通讨论和计划检查不产生回写。

- 发送前先保存项目，记录当前会话、分集和内容快照。每轮使用新的上下文标识，拒绝过期上下文或跨分集目标。如果本轮只提供剧本摘要，不允许据此替换完整剧本。
- 建议只允许修改剧本、素材文字字段和镜头创作字段；新增素材和镜头追加，已有实体以 ID 更新。不能通过建议删除实体、修改文件引用或覆盖整个项目。
- 新素材使用局部 key 供同一建议中的镜头引用，应用生成实际 ID。选择镜头会同时选中其依赖的新增素材；取消素材会取消依赖它的镜头。
- 采用前重新比较涉及字段。无关字段的手动修改、素材文件、图片版本和镜头顺序保留；同一字段已改动或目标已删除时禁止覆盖，其他项目仍可采用。
- 已采用的变更 ID 与项目内容一起保存，重复点击或重新打开不会重复添加。保存失败保留当前草稿，预览中可以重试保存。
- 完整建议与发送前快照保存在应用数据目录 `film-assistant/proposals/`、`film-assistant/contexts/`，业务存储只记录建议索引，聊天工具结果只返回短引用，避免 2000 字符的工具诊断截断。每个会话只保留当前轮的上下文文件，建议按项目、分集、会话隔离。

应用宿主入口为 `main/host/index.ts`，使用 SDK 注入的 storage/files 服务。新工具配置使用 v4 助手档案；已有助手索引首次连接会建立新档案会话，原会话继续保留在本集历史中。

## 开发与验证

在仓库根目录执行：

```sh
pnpm --filter @mewvis/film-workshop dev
pnpm --filter @mewvis/film-workshop check
pnpm --filter @mewvis/film-workshop build
pnpm --filter @mewvis/film-workshop test
```

开发预览的数据与聊天为内存适配，刷新即清空；持久化需在 Mewvis 中验证。运行 `pnpm dev:web` 或 `pnpm dev:desktop` 会通过内置应用登记构建并加载影视工坊。

`test:browser` 使用本地构建产物、生产沙箱文档、SDK 桥与隔离的测试存储验证编辑和重新加载，不接触用户应用数据或真实供应商。需要已安装的 Playwright，可用 `MEWVIS_PLAYWRIGHT_MODULE` 指定模块路径，用 `CHROME_PATH` 指定浏览器。验收图默认写入 `/tmp/mewvis-film-workshop-qa`。

构建后可执行 `node apps/applications/builtins/film-workshop/test/browser-smoke.mjs --preview`，在 `http://127.0.0.1:5188/` 打开使用三部示例作品的生产沙箱预览。该模式使用隔离的内存数据、虚拟文件和模拟聊天；分镜生图返回应用内示例图片，可通过 MEWVIS_FILM_QA_VIDEO 和 MEWVIS_FILM_QA_AUDIO 指定本地视频与音频样本以模拟生成，结构化创作建议使用固定样例，不调用真实模型。支持工作目录、媒体回填与预览检查，不需要 Playwright，重启后重置。可用 `MEWVIS_FILM_PREVIEW_PORT` 调整端口。设计对照和响应式验收记录见仓库根目录 `design-qa.md`。

加上 `--media` 可启动真实合成夹具：使用隔离的示例图片、视频和音频，媒体 SDK 经相同页面桥接调用真实 Server 媒体服务及 FFmpeg，生成的 MP4 回到文件预览。需要先构建 Server 并安装 FFmpeg/FFprobe；去掉 `--preview` 则运行自动化的预览、导出和历史恢复检查。该夹具只使用临时目录，不访问用户工作目录或模型供应商。

## 工作台布局

工作台沿用故事工坊的三栏结构：左侧分集与镜头目录、中间当前步骤编辑、右侧辅助面板。分镜、视频生成和音画同步保留同一镜头选择，步骤之间可以随时往返。项目设定和素材准备为整个项目共享。

分镜设计、视频生成、音画同步采用与预览导出一致的工作区布局：左侧大预览，标题旁使用与预览导出一致的版本菜单；列表展示文件名、时间、来源和当前标记，点击即设为当前镜头使用的版本，不额外显示缩略图条。右侧「创作参数 / 镜头信息」分开编辑并独立滚动，生成与停止操作固定在参数栏底部，页面底部独立提供上一步、下一步导航。音画同步同时显示画面参考、当前配音播放器与真实波形。解除素材关联与删除镜头均需二次确认。窄屏将素材放在参数之前，生成操作跟随参数区域。

右侧只有「助手」和「参考」两个入口。参考面板只读显示本集剧本、当前镜头关联的角色与场景、项目视觉风格，需要修改时跳回对应步骤。角色、场景、道具统一由素材准备维护；镜头台词在分镜设计编辑，音画同步只引用台词。

助手聊天输入区采用故事工坊的输入框结构与尺寸：上下文摘要、可调整高度的文本框、模型选择、权限图标和圆形发送/停止按钮。切换到参考面板会保留未发送草稿。专注模式收起两侧区域；窄屏使用镜头目录抽屉和辅助面板，七步始终单行并通过左右箭头移动。
