# 影视工坊

影视工坊位于 `apps/applications/builtins/film-workshop`，应用 ID 为 `@mewvis/film-workshop`。默认启用，在故事工坊之后显示。首版围绕影视项目的创作流程实现业务，复用现有应用 SDK，不扩展宿主协议。

## 创作流程

借鉴 [AID Studio](https://github.com/gzxx-2025/aid-studio) 的七步流程：项目设定 → 剧本创作 → 素材准备 → 分镜设计 → 视频生成 → 音画同步 → 预览导出。漫剧、短剧、电影与静态漫画共用工作台，静态漫画的音视频步骤可跳过。

当前提供：

- 以最近项目和「继续创作」为主的首页，其他作品使用紧凑列表；继续入口恢复上次分集、步骤与镜头，新项目直接进入项目设定。
- 首页与工作台的七步流程始终单行，隐藏滚动条；空间不足时显示左右箭头，点击移动步骤栏，到达边缘时禁用对应方向。打开项目、切换步骤或改变工作区宽度时，自动把当前步骤移到可见位置。底部常驻前后步骤切换。
- 使用紧凑的字号层级：页面与镜头标题 22px，栏标题 16px，正文与控件 13px，辅助信息 11–12px；助手输入框按故事工坊使用 14px 字号，控件与留白同步收紧。
- 创作助手默认在右侧展开，窄屏通过侧边按钮展开面板；中间只编辑当前镜头，助手上下文包含选中镜头 ID。
- 作品库、新建、搜索、删除和 JSON 导入；导入总是创建独立副本，重建实体 ID 与引用，保留现有项目。
- 项目方向、比例、视觉风格与故事梗概；分集新增、重命名和删除，至少保留一个分集。
- 分集剧本编辑，以及 TXT / Markdown 导入；已有剧本提供追加或替换选择。
- 项目共享的角色、场景与道具设定，支持导入图片、视频、音频、PDF 和文本参考文件，并通过宿主预览。
- 分镜画面、景别、运镜、时长、角色和场景引用；镜头重排、删除，图片提示词与文件备注。分镜支持本地图片导入、生图和多版本选择。
- 按镜头编辑视频提示词、音色和声音设计，配音台词引用分镜内容。
- 制作时间轴、计划检查、Markdown 制作清单与项目 JSON 复制。
- 通过 Chat SDK 连接的创作助手，按项目与分集恢复会话，提供文字建议和计划检查。

示例「雨夜电台」只有在用户主动打开时创建，包含手工编写的剧本、素材与分镜，不模拟生成任务或媒体结果。七步导航为固定步骤视图，尚非可自由编辑的节点画布。

首页封面与示例分镜使用随应用打包的插图，并标注「创作示意」「分镜示意」。它们不属于用户生成的媒体，也不会写入项目 JSON。普通镜头显示文字分镜，文件备注不会被误用为图片预览。

## 持久化与边界

创建项目时选择工作目录，通过 `@mewvis/app-sdk/data` 注册应用工作区，在所选目录中创建 `film-projects/<projectId>/`：

- `project.json`：剧本、素材引用、镜头和生成记录。
- `media/`：分块导入的本地素材。
- `generated/<generationId>/`：每次分镜生成的独立输出。

`film:project:<id>` 只保存工作区索引，媒体路径使用项目内相对路径，不在 JSON 中保存二进制或临时预览地址。旧项目仍可打开，选择工作目录后迁移为文件存储。JSON 导入创建独立的文字计划副本，不复制原项目的媒体文件。

助手索引使用 `film:assistant:v2:<projectId>:<episodeId>:<workspaceId>`，绑定项目工作区；旧项目保留原助手索引。删除项目只移除作品库索引和导航位置，项目文件、素材和历史会话保留。解除素材关联也保留磁盘文件。

助手标题右侧为「会话历史」和「新建会话」。历史按当前项目与分集筛选，显示创建时间并标记当前会话；遵循宿主规则，发送消息后才生成历史记录。新建保留旧记录，切换后保存当前会话引用。发送、回复和切换期间禁用会话操作，创建或切换失败保留当前会话与草稿。面板收起由侧边「助手」入口控制。

导航位置独立保存在 `film:view:<projectId>`，不改变版本 1 的可移植项目格式。删除项目会同时删除其导航位置。失效的分集／镜头引用会回退到项目内有效实体；没有历史位置的项目按现有内容选择起始步骤。

项目格式为 `mewvis-film-project`，版本为 `1`。读取与导入校验格式版本、唯一 ID、素材类型、引用、时长、数组及文本上限；异常数据保留并明确报错，不自动重置或清空库。删除素材会解除所有分集中的对应引用，保留画面与台词。

页面编辑在 650 ms 后自动保存，写入按顺序执行；显示成功仅表示 SDK 写入已完成。手动保存、快捷键 Ctrl/Cmd+S 和返回作品库均执行保存，返回等待最新更改提交。保存失败保留页面草稿并显示错误，修正后可重试。快速关闭窗口前应确认显示「已保存」。首版未实现多窗口同项目冲突合并。

工作目录项目允许最大 16 MiB 的 JSON，素材通过文件 SDK 按 64 KiB 分块导入，文件大小不受业务存储的 JSON 限制。尚未选择工作目录的旧项目保留 220 KiB 的存储上限。文件备注不能作为生成成功或成片完成证据，制作计划检查通过只说明文字计划准备就绪。复制通过 SDK，需要用户操作。

助手提供文字建议；分镜生图由专用按钮发起，生成图片的回填由工坊管理。小项目上下文包含完整数据，大项目提供有界摘要并明确标记，不能将截取的镜头当成完整计划检查。回复期间的项目修改等待会话空闲后同步，不打断当前回复。有工作目录的项目使用其注册工作区，旧项目暂用应用默认工作区；仅确认「未找到聊天记录」时重建空会话，其他连接错误保留引用并允许重试。

应用声明 `application-data`、`application-workspaces`、`workspace-files` 和 `chat`。Agent 仅可在当前工作区读写文件，允许访问所选模型及媒体输出所需的网络，仍受宿主权限及沙箱约束，不允许执行子进程。助手工具范围为 `film_check_delivery` 与 `generate_media`。模型、凭据和生成能力全部沿用宿主当前选中模型，不读取其他应用私有存储。

## 分镜生图与回填

填写镜头画面或图片提示词后，点击「生成分镜图片」。工坊先保存项目和请求记录，再向当前分集的助手会话提交一次生成请求。生成使用当前模型的 `image-generation` 配置，比例、视觉风格和关联角色／场景描述随请求传递。失败和停止后不自动重新提交付费请求。

生成记录固定项目、分集、镜头、会话及输出子目录，结果只从对应会话轮次的 `generate_media` 结构化结果提取。回填前检查返回文件路径位于本次请求目录，并通过宿主确认文件存在；重复快照按文件路径去重。切换镜头不会改变回填目标。重新生成保留旧图，生成期间手动选择其他图片时保留手动选择。删除目标镜头后返回的文件仍保存在项目媒体记录中，不会绑定其他镜头。

界面提供进度、停止和重新连接。项目重新打开时恢复对未结束请求的监听，不重新发起生成。停止调用宿主会话的停止能力；上游是否取消由宿主和供应商决定，工坊不会声称已退费或已取消供应商账单。关闭工坊后宿主任务可以继续运行，再次打开后恢复结果关联。

## 开发与验证

在仓库根目录执行：

```sh
pnpm --filter @mewvis/film-workshop dev
pnpm --filter @mewvis/film-workshop check
pnpm --filter @mewvis/film-workshop build
pnpm --filter @mewvis/film-workshop test
```

开发预览的数据与聊天为内存适配，刷新即清空；持久化需在 Mewvis 中验证。运行 `pnpm dev:web` 或 `pnpm dev:desktop` 会通过内置应用登记构建并加载影视工坊。

`test:browser` 使用本地构建产物、生产沙箱文档、SDK 桥与隔离的测试存储验证编辑和重新加载，不接触用户应用数据或真实供应商。需要已安装的 Playwright，可用 `MEWVIS_PLAYWRIGHT_MODULE` 指定模块路径，用 `CHROME_PATH` 指定浏览器。验收图默认写入 `/tmp/mewvis-film-workshop-qa`。

构建后可执行 `node apps/applications/builtins/film-workshop/test/browser-smoke.mjs --preview`，在 `http://127.0.0.1:5188/` 打开使用三部示例作品的生产沙箱预览。该模式使用隔离的内存数据、虚拟文件和模拟聊天；分镜生图返回应用内示例图片，不调用真实模型。支持工作目录、图片回填与预览检查，不需要 Playwright，重启后重置。可用 `MEWVIS_FILM_PREVIEW_PORT` 调整端口。设计对照和响应式验收记录见仓库根目录 `design-qa.md`。

## 工作台布局

工作台沿用故事工坊的三栏结构：左侧分集与镜头目录、中间当前步骤编辑、右侧辅助面板。分镜、视频生成和音画同步保留同一镜头选择，步骤之间可以随时往返。项目设定和素材准备为整个项目共享。

右侧只有「助手」和「参考」两个入口。参考面板只读显示本集剧本、当前镜头关联的角色与场景、项目视觉风格，需要修改时跳回对应步骤。角色、场景、道具统一由素材准备维护；镜头台词在分镜设计编辑，音画同步只引用台词。

助手聊天输入区采用故事工坊的输入框结构与尺寸：上下文摘要、可调整高度的文本框、模型选择、权限图标和圆形发送/停止按钮。切换到参考面板会保留未发送草稿。专注模式收起两侧区域；窄屏使用镜头目录抽屉和辅助面板，七步始终单行并通过左右箭头移动。
