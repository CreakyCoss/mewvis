# 游戏沙盘

应用位于 `apps/applications/builtins/gameplay-lab`，定位为按游戏类型组织的策划与玩法原型验证工作台。完整产品方向及后续范围见[调整规划](../../../apps/applications/builtins/gameplay-lab/docs/roadmap.md)。

## 创建与编辑

每次打开先进入项目库。填写项目名称和父目录，选择游戏类型及玩法方向，从零创建或复制该类型的示例。示例不自动初始化成用户项目。空白项目不预填内容，可暂不选方向；未完成的内容可正常保存，试玩前通过类型、方向、模型、模拟器及具体规则校验。

当前提供：

- 卡牌 → 组合计分：规则定义、卡牌与回合、策略与场景、实验、版本。支持自定牌池、手牌、选择、计分、弃置和补牌。
- 回合资源经营 → 回合资源发展：规则定义、流程与产出、策略与场景、实验、版本。支持资源成本、周期产出、能力与阈值目标。
- 文字冒险 → 条件分支叙事：人物、剧情与选择、状态变量、试玩记录、版本。使用独立叙事模型与执行器。

棋盘经济和塔防尚未提供。当前组合计分不等于完整小丑牌机制，回合资源发展不包含大富翁棋盘规则。

策划概览记录设计目标、核心体验/循环和待验证问题；就绪清单列出缺项与编辑入口。示例是起点，玩法方向决定规则体系和可验证范围，自动玩家策略只负责选择合法行动。

## 两类执行路径

卡牌和经营继续复用 `gameplay-model-v1` 的数值规则核心，按类型组织界面与约束。这仍是受限子集，完整卡牌对象、牌区和触发体系待后续完善。

叙事使用 `gameplay-narrative-v1`，定义人物、节点、选项、结局与变量，不要求数值行动、回合或达标阈值。布尔、整数和文本变量可参与类型匹配的条件；条件全部满足才可选择。后果按顺序执行设置或数字加减，再进入目标剧情。引用中的人物、变量和节点不能直接删除。

所有后果在副本上执行，失败不留下部分修改。没有合法选项标为条件死路，200次选择上限单独提示，不冒充结局。叙事报告提供连线结构可达性，不穷举条件组合，也不以自动数值指标代替人工体验判断。

## 试玩、版本和实验

数值玩法保留1–2位参与者、场景、自定义自动玩家、策略对照、版本对照与单参数扫描。各组固定初始条件与种子，报告目标、步数、截断、异常及配对差值。参数扫描不改写原策划。

叙事提供手动选择、条件拦截原因、状态变化和路径回放；重开记录可继续未完成路径。命名版本冻结设计模型、类型、方向、模拟器和说明，可复制为草稿。修改草稿不改写历史模型。

新建数值对局/实验使用 `gameplay-run-v3` / `gameplay-experiment-v4`；叙事记录使用 `gameplay-story-run-v1`。读取记录按冻结模型和执行器版本重算，损坏或不支持的记录单独提示并保留原件。数值旧版记录仍可读取。

## 数据与宿主接入

应用通过公开 SDK 选择目录、独占创建项目、登记工作区及原子读写 JSON。普通编辑只写用户项目，已有目录拒绝覆盖。宿主数据库仅保存 `gameplay-lab:library:v2` 项目位置索引，加载时清理废弃的旧版数据库项目记录。

- `models/core.json`：数值或叙事模型，附带 `gameplay-project-v4` 元数据，保存类型、方向、示例来源、模拟器、设计说明及命名版本。旧目录项目v2/v3可读取，修改保存后写入v4。
- `configs/playtest.json`：仅数值玩法使用的场景、玩家策略与实验选择。
- `runs/`：数值对局或叙事路径的冻结记录。
- `experiments/`：数值实验计划及样本。
- `backups/`：同类示例应用/重置前的完整副本。

策划文件上限4MiB，叙事记录上限4MiB，数值记录上限16MiB。超出时拒绝写入，避免生成无法重开的文件。外部修改后拒绝旧页面覆盖，须显式重新读取。更换类型不提供自动规则转换。

紧凑字号、宿主明暗主题和沉浸式安全区继续保留，窄屏输入文字16px、主要控件点击高度44px。

## 开发与验收

```sh
pnpm --filter @mewvis/gameplay-lab dev --port 5192
pnpm --filter @mewvis/gameplay-lab check
pnpm --filter @mewvis/gameplay-lab test
pnpm --filter @mewvis/gameplay-lab test:projects
pnpm --filter @mewvis/gameplay-lab build
pnpm --filter @mewvis/gameplay-lab preview:packed
```

普通开发预览不提供完整文件服务，不回退浏览器存储。`preview:packed` 使用生产沙盒桥接、数据与文件服务、工作区登记和SQLite，在临时目录中验证；目录选择器为验收替身，真实原生选择仍由宿主负责。

本轮证据见 `output/gameplay-lab/typed-design-qa/`，此前场景、比较和从零建项证据分别保留在对应QA目录。
