# Tavern Prompt Quality Evaluation

本评估用于优化酒馆输出模式和风格套餐。真实模型输出报告默认写入
`apps/desktop/tmp/tavern-prompt-quality-eval.json`，该目录不提交。

## 评估方法

1. 硬指标评分
   - XML 合同是否使用 canonical tag，解析后是否无协议残留。
   - 是否贴合 dialogue-chat、novel-prose、third-person-prose 的呈现形态。
   - 是否承接场景目标和关键线索。
   - 是否保持角色边界，不替用户做选择，不写其他角色未公开心理。
   - 是否有具体动作/环境细节，避免空泛氛围和模板句。

2. SPEED 模型内容裁判
   - 使用 `SPEED_MODEL_IDS` 中可用模型评估最终可见片段。
   - 评估重点不是 XML，而是小说模式是否连成小说、对话模式是否像真人现场回应、环境描写是否服务剧情。

3. Codex 人工复核
   - 我会阅读最终可见片段并给出人工分，作为套餐排序的重要依据。
   - 人工复核更重视阅读体验、角色真人感、环境比例、互动空间和“是否像 AI 在总结”。

## 结论

- 默认推荐小说正文稳态、克制文学、镜头悬疑。
- 第三人称旁白可作为可选模式，但需要持续抑制直接对白和菜单式收尾。
- 对话模式优先推荐写实对话；轻快对话适合轻松场景，不适合严肃调查默认。
