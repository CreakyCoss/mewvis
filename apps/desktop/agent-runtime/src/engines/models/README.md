# 模型思考等级预设

`built-in-catalog/config.ts` 只提供前端的快捷配置参考，`data.ts` 保持为同步生成的基础元数据。

每个模型可以按 API 格式提供预设：

```ts
"model-id": {
  thinking: {
    "openai-completions": {
      levels: [
        { value: "off", label: "关闭" },
        { value: "high", label: "高" },
      ],
      defaultLevel: "high",
    },
  },
}
```

用户可在 LLM 设置的模型条目中添加、删除等级，修改显示名称和默认值。等级值是字符串，可以从前端通用预设中选择，也可以输入自定义值。保存的设置优先于内置预设；恢复模型预设会清除该覆盖配置。空列表表示不提供等级选项，默认值为空表示不指定等级。

前端将选项显示在对话的模型菜单中，所选值随会话保存。切换模型使用新模型的默认值。

运行请求只携带 `thinkingLevel`，不携带可选等级列表。后端不读取这份目录来校验、替换或补全请求等级。Pi 适配层利用 SDK 的等级映射传递自定义值，普通聊天、主 Agent 和子 Agent 共用；具体提供方是否接受该值由其接口决定。
