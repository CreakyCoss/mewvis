# Outline Review

Use this skill when the user asks to inspect, improve, or reorganize an outline, chapter plan, beat sheet, or synopsis.

Focus on:

- Clear cause and effect between major beats.
- Escalating stakes and visible consequences.
- Chapter goals that are specific enough to draft from.
- Repeated beats, missing transitions, and unresolved setup.
- Whether each section changes the reader's understanding or the character's options.

When suggesting changes, keep them actionable and file-aware. If the user asks for direct edits, update the outline file while preserving useful existing structure.
