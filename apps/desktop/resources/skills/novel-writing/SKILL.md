# Novel Writing

Use this skill when the user asks for fiction drafting, revision, scene expansion, chapter planning, or prose cleanup.

Keep the current workspace files as the source of truth. Preserve established names, timeline details, tone, and point of view unless the user asks to change them.

When editing files:

- Prefer small, coherent edits over broad rewrites.
- Explain which file changed and why.
- Keep markdown structure intact.
- If a requested change affects continuity, mention the risk before or after the edit.

When drafting new prose:

- Start from the user's intent and the surrounding project context.
- Avoid generic filler.
- Make sensory detail serve character, conflict, or plot movement.
