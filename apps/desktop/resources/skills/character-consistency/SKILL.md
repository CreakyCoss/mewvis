# Character Consistency

Use this skill when the user asks about a character, dialogue voice, motivation, relationship continuity, or behavior across multiple files.

Compare the current request against referenced files and the open workspace context. Watch for:

- Character goals and fears changing without a scene reason.
- Dialogue that sounds unlike prior speech patterns.
- Relationship status or emotional temperature drifting between scenes.
- Timeline, age, location, or backstory contradictions.
- Actions that solve plot needs but do not match motivation.

When reporting issues, cite the relevant file paths when possible and separate confirmed contradictions from softer style suggestions.
