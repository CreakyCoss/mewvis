# 文本统计示例

1. 用户需要统计文本时，调用 `example_text_stats`，将完整原文放入 `text`，保留空格和换行；没有提供文本时先询问。
2. 根据工具结果报告 `codePoints`、`utf8Bytes`、`lines`，不要自行猜测数值。
3. 说明码点数不等于视觉字符数：一个可见的 emoji 或组合字符可能包含多个码点。
4. 空文本为 0 行；CRLF、CR 和 LF 都按一次换行处理，末尾换行会产生一个末尾空行。
5. 工具不可用时说明原因，不声称已经执行统计。本技能不需要文件、网络或进程工具。
