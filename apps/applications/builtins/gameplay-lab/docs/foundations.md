# 基础配置与编辑能力

日期：2026-10-29。基础编辑能力服务于玩法框架。当前主流程与交付范围见[玩法框架与游戏试玩](frameworks.md)。

## 三层责任

| 层次     | 责任与当前范围                                                                               |
| -------- | -------------------------------------------------------------------------------------------- |
| 应用基础 | 项目目录、保存与冲突保护、内容查找、引用检查、版本、记录、不兼容数据的提示及确认删除         |
| 类型基础 | 卡牌定义、牌库与牌区；经营的资源、能力与行动；叙事的人物、剧情、选项与变量。各自保留独立表达 |
| 玩法框架 | 组合计分、回合资源发展、条件分支叙事的具体执行规则。连关、奖励、商店属于后续具体玩法框架     |

拥有配置表单并不表示它是所有类型都需要的基础能力。关卡、奖励和构筑不能直接成为所有项目或所有卡牌项目的必填配置。

## 现状与缺口

| 能力                     | 状态                       | 后续范围                                                   |
| ------------------------ | -------------------------- | ---------------------------------------------------------- |
| 空白建项、目录与自动保存 | 已有                       | 保持从零创建，示例可选                                     |
| 类型专属内容编辑         | 已有最小闭环               | 叙事内容复制与顺序调整、较大内容列表的批量编辑仍需完善     |
| 内容目录与草稿查找       | 本轮补齐                   | 按名称、说明、标识查找，按类型筛选；同名内容按标识区分     |
| 草稿引用与定位           | 本轮补齐                   | 使用位置与依赖内容可直接跳到编辑器；缺失引用明确展示       |
| 内容完整性检查与修复入口 | 本轮补齐                   | 显示当前模型校验问题，定位具体卡牌、牌库、定义、剧情或变量 |
| 场景与自动玩家引用       | 已有引用检查，本轮补充展示 | 从目录进入策略与场景检查；跨配置的逐项定位尚未补齐         |
| 命名版本                 | 已有冻结与复制草稿         | 重命名、明确删除及差异浏览仍需完善                         |
| 编辑撤销与重做           | 待做                       | 需要处理输入分组、持久化和切换项目边界                     |

## 本轮：内容目录与检查

三个工作区都提供“内容目录”。目录以当前草稿建立只读索引，不写入项目 JSON，不改变模型、玩法规则、版本或运行快照。

- 经营列出状态、能力、行动、目标和周期流程，展示消耗、前置、效果、数值来源、目标和周期引用。
- 卡牌增加卡牌定义与牌库，展示牌库数量引用，以及牌库、计分行动与得分状态之间的关系。
- 叙事列出人物、变量、剧情、选项与叙事入口；展示发言者、目标剧情、条件变量及后果变量。选项可直接定位到所属剧情中的对应编辑区域。
- 搜索支持名称、说明、标识及多个关键词，类型筛选只影响目录显示。
- 缺失引用作为待修复依赖显示；内容检查使用现有校验器。它检查草稿完整性，不承诺通过试玩方向、模拟器或场景检查。
- 跳转后滚动并聚焦对应编辑区域；搜索、筛选与选中内容在本次工作区内返回目录时保留。

目录不替代各类型的编辑器，也不建立统一的游戏内容存储模型。类型领域输出索引与引用，项目层负责展示和导航。

## 接下来的优先级

先完善已有内容的复制、顺序与版本管理，再评估撤销/重做。新增属性与规则必须有明确的类型语义、校验及使用方式，避免先加入无法验证的自由字段。

优先验证框架专属编辑与游戏试玩的完整流程。内容目录作为辅助管理入口；新的玩法框架分别说明模型要求、执行与游戏界面范围。
