# 抽牌、弃牌与限时专注

组合计分可以在“玩法组合”启用“卡牌能力”。侧栏随之出现配置页，牌桌出现能力面板。单人和双人场景均可使用，能力只影响使用者自己的牌区与资源。

## 配置自己的能力

启用时准备一项“换牌”：弃 1 张、抽 1 张。可修改这项能力，也可添加抽牌、弃牌或专注能力作为编辑起点。每局最多配置 8 项，每项可用 1–3 次。预设只提供机制起点，自己的卡牌内容仍需填写。

| 配置         | 含义                                                       |
| ------------ | ---------------------------------------------------------- |
| 目标牌库     | 使用该玩家在所选牌库中的手牌、抽牌区与弃牌区               |
| 选牌弃置数量 | 手动选择恰好这么多张自己的实体手牌，范围 0–10              |
| 最多抽牌数量 | 抽到可用张数或手牌容量为止，范围 0–10                      |
| 费用资源     | 选择现有数值状态，或不收取费用；可在高级规则中添加库存状态 |
| 基础费用     | 1–1,000,000，实际费用受专注减免，最低为 0                  |
| 专注减免     | 降低“卡牌能力”模块中每次能力的资源费用，范围 1–3           |
| 持续阶段     | 持续 1–3 个自己的行动阶段，包含施加当阶段                  |

每项能力至少包含抽牌、弃牌或专注效果。抽弃牌需要有效牌库，弃牌数量不能超过该牌库的手牌容量；收费需要有效资源。草稿可保留未完成的名称和引用，试玩前会提示问题。被能力引用的资源和牌库不能直接删除，需要先解除引用；关闭模块会保留这些内容。

## 在牌桌使用

轮到自己时，选择能力；若需要弃牌，在能力面板选择对应副本，再点击“使用能力”。普通出牌的选牌区域独立使用。能力不消耗普通行动次数，各项能力的剩余次数分别显示。

执行顺序固定为：支付费用 → 弃牌 → 抽牌 → 施加专注 → 扣除一次使用次数。整个过程在副本上结算，任一步失败不扣费用、不移动牌，也不扣次数。保存成功后牌桌才显示结果。

抽牌遵守所选牌库的容量和回收规则。手牌已满时，纯抽牌能力不可用；换牌先弃置，因此可以腾出空间。抽牌区不足时，只抽实际可用数量；若设置弃牌回收，会按冻结随机序列洗回弃牌，刚弃置的牌也可能再次抽到。完全没有可抽牌时，包含抽牌的能力不可用。

公开事件会记录费用变化、弃置牌及抽牌张数。抽到的具体牌只出现在自己的手牌中；抽牌顺序和他人手牌不进入正常玩家视图。检查面板供设计检查使用，可以展开完整牌区。

## 专注何时结束

专注在自己的行动阶段结束时减 1。主动“结束行动”或用完普通行动次数，都算结束一个阶段；双人场景中，对手阶段结束不减少自己的持续时间。再次施加时覆盖旧状态，不叠加。

减免只作用于“卡牌能力”中的费用，不修改普通行动成本，也不修改洞察技能。施加专注的能力本次先按旧状态支付费用，随后新状态才生效。只施加专注且已有相同或更强、持续时间不短的状态时，无须重复使用。

## 两套从空白建立的规则

两套规则均从“基础计分”创建，手动定义火花（3 分）和星辉（7 分），各 4 张；手牌容量 5，不自动补牌，弃牌不回收，固定倍率 1。另建库存状态“能量”，初始为 4。它们使用同一套执行器。

| 规则           | 换牌与专注                                   | 付费补牌                                         |
| -------------- | -------------------------------------------- | ------------------------------------------------ |
| 开局抽牌       | 3 张                                         | 2 张                                             |
| 主要能力       | 弃 1、抽 1，每局 3 次                        | 不弃牌、最多抽 2，每局 3 次                      |
| 基础费用       | 每次 2 能量                                  | 每次 2 能量                                      |
| 专注能力       | 免费，减免 1，持续 2 个自己的阶段，每局 1 次 | 相同                                             |
| 目标           | 15 分                                        | 25 分                                            |
| 种子 42 的验收 | 三次换牌后组合得到 17 分，完成目标           | 手牌满时暂停补牌，出牌后再补，累计 30 分完成目标 |

第一套主要调整有限手牌的质量，第二套通过费用和容量控制可使用的牌量。已验证手动能力操作、自动玩家、保存重开和冻结回放；这些配置没有增加新的核心代码或内置内容预设。界面证据保存在本地 `output/gameplay-lab/card-abilities-qa/`。

## 保存、回放与开发接入

能力配置随命名版本和开局模型冻结，次数与专注状态进入逐步模块快照。回放到能力使用前不会提前显示抽牌或状态，回放期间不能执行能力。关闭草稿模块或修改费用不影响旧局；读取时重放冻结命令并校验记录，修改过的记录会被拒绝加载并保留原文件。

`card-abilities@1` 依赖牌区、抽牌堆、资源、回合结束和确定性随机能力，通过注册提供配置、引用检查、编辑器与牌桌区域。共享主动能力契约增加自己的目标，保留洞察默认的对手目标。`afterAdvance` 在声明的 `after-command` 时机按模块依赖顺序执行，并与原命令一起提交；后续结算抛错时，整个操作回滚。抽牌原语在副本上处理容量、回收与随机序列。旧模型和关闭此模块的对局不产生新的状态或行为。

当前只提供这组受控效果与专注状态，不包含任意效果链或通用状态脚本。
