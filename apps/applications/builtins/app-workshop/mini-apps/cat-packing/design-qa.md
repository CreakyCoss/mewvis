## 验收限制与范围

- CUA 的坐标点击与拖拽未进入游戏 iframe：原生视口和指定视口下均只聚焦外层运行容器。不能据此宣称鼠标或触屏拖拽已实测通过。拖拽代码使用 Pointer Events、指针捕获、占格预览及同一个已验证的落位规则；仍建议真实鼠标与触屏补测。点击与键盘路径已实测可完成游戏。
- 独立浏览器预览的运行状态由 SDK 内存模拟；返回工坊再运行可保留，整页刷新会清除模拟状态。正式运行通过宿主 state API 持久化，本次没有修改用户真实工作区存档。
- 只实现首章 8 关。阳光窗台与阁楼派对为明确禁用的未来章节，不参与可玩关卡总数。
- 新关卡按实际可解布局制作，早期棋盘较小；缩略图直接反映关卡真实比例。图稿中的装饰性纸箱形状与下一关猫头细节不逐像素复制。
