# 故事写作工作台视觉标准

以长时间写作、阅读与对话为主。目录、正文、助手保持三栏结构，使用应用已有的字体和语义颜色。实际 token 位于 `tokens.css`，作用于工作台 `.sw-shell` 与资料弹窗 `.sd-dialog`，新增元素优先复用这些角色。

## 字体层级

| 角色     | 字号      | 行高 | 字重      | 用途                                   |
| -------- | --------- | ---- | --------- | -------------------------------------- |
| 辅助信息 | 12px      | 1.5  | 400       | 字数、保存状态、模型、上下文、工具名称 |
| 界面正文 | 14px      | 1.5  | 400 / 500 | 章节目录、标签页、按钮、搜索           |
| 面板标题 | 16px      | 1.5  | 600       | 书名、创作助手；空状态标题用 500       |
| 章节标题 | 24px      | 1.5  | 600       | 正文、细纲、记录标题                   |
| 小说正文 | 默认 20px | 1.8  | 400       | 宋体，保留作者输入的换行与空行         |
| 助手内容 | 14px      | 1.75 | 400       | 对话、建议正文、输入框                 |

界面字体继承应用系统字体。小说正文和章节标题用 `Songti SC → STSong → Noto Serif CJK SC → ui-serif`。不引入远程字体。界面文字不小于 12px，不用缩小字号解决长文本，改用换行、截断与完整标题提示。

正文提供 18 / 20 / 22 / 24 / 26px 五档；窄屏最多显示 20px，保留较小档位。默认值与档位位于 `index.tsx`，选择值通过 `--sw-reading-size` 传入，避免 `!important` 覆盖字号。

## 间距与尺寸

| 间距 | 用途                               |
| ---- | ---------------------------------- |
| 4px  | 紧邻图标操作、工具之间             |
| 8px  | 图标与文字、控件内边距             |
| 12px | 小组件之间、输入框内边距           |
| 16px | 目录边距、紧凑工具栏、局部内容分组 |
| 24px | 助手侧边距、消息之间、内容区段之间 |
| 32px | 标题与正文之间、空状态上方         |
| 48px | 宽屏稿纸侧边距与顶部留白           |

- 顶部栏、章节标签栏、助手标题栏统一 56px；三栏的内容起点对齐。
- 普通按钮、搜索框、发送按钮 36px；图标按钮 32px；目录行和底部状态栏 40px。
- 右侧工具栏项目桌面 60px、窄屏 64px，图标 18px；沿用 Lucide，使用浅色选中背景与 2px 侧边标记。
- 稿纸最大宽度 800px；左右留白依次为宽屏 48px、≤1200px 32px、≤700px 24px。
- 助手默认宽度 320–400px，可拖拽至 720px；目录默认宽度 216–264px，紧凑桌面为 200px，可拖拽至 420px。两侧宽度上限随窗口收窄以保留至少 300px 正文区域；工具栏 56px，窄屏延续抽屉交互。
- 容器圆角 8px；紧凑图标操作圆角 4px，目录行沿用 6px。细边框、字形光学校正和 2px 行间分隔不受 4px 间距网格限制。

## 资料列表与表单

- 资料面板左右边距 16px；数量与 36px「新增资料」按钮固定在顶部，列表独立滚动。空状态也使用这一入口。
- 资料卡片最小高度 68px，内边距 12px，卡片间距 8px，分组间距 24px，圆角 8px。图标容器 32px，图标 16px；标题 14px / 500，资料类型 12px。标题最多两行，通过完整标题提示补充；不重复显示同名类型。
- 选中资料使用主色细边框、浅主色背景和图标，不增加标题字号。分组标题和数量使用 12px。
- 新增与编辑共用最大 880px 的弹窗，桌面内容边距 24px、窄屏 16px；标题 16px，说明和字段标签 14px，辅助说明 12px。
- 基本字段桌面两列，列间与字段间距 24px；长文本、对象与列表占满整行。≤640px 改为单列，内容独立滚动，底部取消和保存操作始终可见。
- 输入框、选择框与分组标签统一 36px；字段标签到输入框间距 8px。资料类型从当前大纲、角色、设定或伏笔入口选择可创建的默认类型，保留手动切换。

## 扩展与验证

正文空行属于故事内容，不能通过格式化或保存来改变。视觉优化只调整字体和行高。专注模式保持相同阅读宽度。颜色、焦点环和浮层阴影使用应用语义 token，浅色与深色共享尺寸标准。

新增组件先确定文字角色，再选择间距层级；避免为单个按钮新增 11 / 13 / 17 / 23px 等字号，或 9 / 10 / 14 / 18px 等内容间距。验证时覆盖 1280px 桌面、紧凑桌面与 390px 窄屏，并检查选区工具、助手建议、细纲、深色和专注状态。
