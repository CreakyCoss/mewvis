## Findings

- [P2，已修复] 工作区、历史、新增表单和 ID 连接纵向堆叠，主次不清。改为工作区列表与会话列表两栏，搜索和新对话固定在会话栏顶部，低频 ID 入口放在底部。
- [P2，已修复] 原生 `select` 展开菜单由平台绘制，与应用主题不一致。会话管理器改用主题一致的工作区按钮列表，无原生下拉框；窄窗为可横向滚动的工作区列表。
- [P1，已修复] 仅浏览另一个工作区就会改变主页面。管理器独立维护浏览状态，只有成功打开／新建会话才更新主页面和已保存选择；关闭弹窗保持当前会话与草稿。
- [P2，已修复] 新增工作区和 ID 连接挤在同一页，连接失败后弹窗已关闭。两项操作改为独立步骤，保留返回与取消；验证会话成功后才关闭，失败时保留输入并在弹窗内显示错误。
- [P2，已修复] 初次检查发现连接失败提示会残留到新增工作区步骤，空状态文案末行只剩一个字。切换步骤清理操作错误，空状态采用平衡换行；`03-create-workspace.png` 和 `10-final-empty.png` 复核通过。
