# 调试台 · AI 与对话页面验收

日期：2026-10-03。用户反馈：页面内容太多，影响操作和显示。本轮以现有能力展厅为视觉基础，重新安排聊天页的信息层级。旧版紧凑密度报告保存在 `prototypes/chat-playground-redesign/chat-focus/pre-revision-design-qa.md`。

## Findings

- [P1，已修复] 687 × 690 视口中，工作区表单、连接信息、界面切换和示例占据首屏，输入框从 y=809 开始，无法直接输入。移除聊天页的重复大标题，把工作区与历史移入「会话」面板；消息区填满剩余空间，输入框留在底部。
- [P2，已修复] 外层页面和消息区域同时滚动，窄窗双视图原本固定堆叠为 960px。现在只滚动消息；宽窗双栏，聊天容器不足 780px 时切换主／第二视图，保持独立草稿。
- [P2，已修复] 低频调试信息持续占用聊天空间。示例、接入代码、界面模式和检查器分别按需打开；保留原有会话与调试能力。
- [P2，已修复] 带入示例后，重连或切换工作区会重新弹出示例面板。示例首次展示后记录状态，仅新的外部示例再次触发自动展示。
- [P2，代码已修复] 发送图标被应用的通用颜色继承规则覆盖，禁用态对比度不足；悬停背景也覆盖了共享组件。通用颜色和悬停规则现排除带 `data-slot` 的共享控件，恢复组件自身样式。按用户要求，追加修复的界面验证由用户完成。

本轮范围内无待修复的 P0 / P1 / P2 问题。
